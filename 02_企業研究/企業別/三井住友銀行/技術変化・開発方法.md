# 三井住友銀行 技術変化・開発方法

## 位置づけ

このノートは、三井住友銀行/SMBCグループの公式発信から、IT・デジタル職に関係する技術変化と開発方法の変化を整理する。

## 確認できた技術発信の要点

- 新中期経営計画では、ITトランスフォーメーション、IT投資拡大、開発力強化、生成AIを含む技術活用が示されている。
- 2025年度決算投資家説明会では、3年間で1兆円のIT投資、クラウド化比率8%から50%、AI・クラウド人材300人から1,000人、AI投入1,000億円が示されている。
- SMBC-GAIは、130万件の社内文書をRAGで横断検索する方向へ拡張されている。
- 日本総研・ULS提携では、AIを開発プロセスの中核に据えるAIネイティブ開発モデルの構築が示されている。
- 日本総研・富士通の実証では、RHEL更改の非互換抽出に生成AIを使い、抽出時間を約65%削減した。
- Google Workspaceとのマルチクラウド運用では、クラウド時代のBCPとレジリエンスが重視されている。
- サイバーセキュリティは経営上のトップリスクとして扱われ、CISO、SOC、CSIRT、CFC、700名以上の専門スタッフによる体制が確認できる。

## 主要技術テーマ

### 生成AI・RAG

- SMBC-GAIは、文章作成、要約、翻訳、議事録、調査レポート、社内文書検索などへ用途が広がっている。
- 130万件の社内文書をRAGで検索し、参照元表示や元資料画像確認によりハルシネーション対策を行っている。
- SMBC-GAI、Copilot、Geminiを用途に応じて使い分けるマルチLLM活用も確認できる。

### AIネイティブ開発

- 日本総研とULSコンサルティングは、AIを開発プロセスの補助ではなく中核に据えるAIネイティブ開発モデルを構築すると発表している。
- 企画構想、設計、プロジェクトマネジメント、実装までAI活用を前提に再設計した開発標準を定義する。
- 開発基盤、ナレッジベース、専門人材育成、ビジネスアナリスト・ITアーキテクト人材強化も示されている。

### レガシー刷新・保守高度化

- RHEL更改の生成AI実証では、C言語およびbashで記述された約380キロステップのアプリケーションを対象に、非互換情報を抽出した。
- 生成AIにより、リリースノートなど膨大なドキュメントの目視・手作業確認を効率化している。

### クラウド・レジリエンス

- クラウド化比率を8%から50%へ高める方針が示されている。
- Microsoft環境に加えGoogle Workspaceを並行稼働させ、同一メールアドレスで利用可能なバックアップ基盤を構築している。
- サイバー攻撃、自然災害、システム障害を前提に、業務を止めない状態を作ることが重視されている。

### サイバーセキュリティ

- サイバーセキュリティリスクは経営上のトップリスク。
- 脅威インテリジェンス、脆弱性診断、ペネトレーションテスト、SOC、CSIRT、CFC、金融ISAC等との連携が確認できる。
- システム企画者向け研修を通じてセキュリティ・バイ・デザインを浸透させている。

## 開発方法・現場業務への影響

| 変化 | 内容 | 現場への影響 |
| --- | --- | --- |
| AI補助からAI前提へ | AIネイティブ開発、LLM-CoE、RHEL更改実証 | 企画、設計、PM、実装、保守、レビューがAI活用前提になる |
| レガシー理解の高度化 | C言語/bash、COBOL等の既存資産理解 | AIを使いながらも人間が影響判断・品質判断を担う |
| クラウド化の本格化 | クラウド化比率8%から50% | アーキテクチャ、運用、セキュリティ、コスト、BCPの理解が必要 |
| マルチLLM運用 | SMBC-GAI、Copilot、Gemini | モデル特性、利用範囲、権限、データ保護を設計する必要 |
| RAG運用 | 130万件社内文書検索、参照元提示 | データ整備、権限管理、根拠確認、利用者教育が重要 |
| 顧客向けAI | AIオペレーター | AIに任せる範囲と有人対応の境界設計が重要 |
| セキュリティ・バイ・デザイン | システム企画者向け研修、CISO体制 | 企画・設計段階からセキュリティを組み込む |

## 品質・セキュリティ・説明責任

- SMBC-GAIでは、生成AIの回答にハルシネーションが生じ得ることを前提に、利用者責任、参照元表示、元資料確認が示されている。
- 顧客向けAIオペレーターでは、本人確認が不要な一般照会を対象にし、本人確認が必要な手続は有人対応に残している。
- サイバーセキュリティでは、グループ/グローバルで700名以上の専門スタッフ体制が示されている。
- 金融ITでは、技術導入の速さだけでなく、根拠、監査、品質、セキュリティ、業務継続の設計が不可欠である。
