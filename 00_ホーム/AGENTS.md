# 00_ホーム/AGENTS.md

## 文字コード

このファイルとこのフォルダ配下のMarkdownファイルは、文字化けを防ぐためUTF-8で開く。

## 目的

このフォルダは、Obsidian Basesによる一覧確認に使う。

本文を書く場所ではなく、企業研究、ES、面接対策、GD対策、メモ素材を横断して確認する場所である。

## 推奨Base

```text
企業一覧.base
面接対策一覧.base
GD対策一覧.base
メモ素材一覧.base
```

## 方針

- `企業一覧.base` は `01_企業別/` 配下の企業入口、ES入口、ES設問、企業分析、素材要約、企業別面接対策、企業別GD対策を横断して見る。
- 企業研究の事実本文は各社の `01_企業別/企業名/企業研究/` を直接見る。現時点では企業研究専用Baseは置いていない。
- ESは `企業一覧.base` の `ES入口`、`ES設問` ビューで横断確認する。
- 共通面接メモ、企業別面接対策、志望理由は `面接対策一覧.base` で横断確認する。
- GDの型、発言テンプレ、企業別GD対策は `GD対策一覧.base` で横断確認する。
- 原典、草案、素材メモは `メモ素材一覧.base` で見る。ただし現在のBaseは主に `type: webclip` と `type: material_note` を対象にしている。
- 自己分析やDailyは独立Baseにしない。

## 編集ルール

- `00_ホーム/` 内には長文メモを置かない。
- Baseで使うProperties名は勝手に変更しない。
- 一覧で見たい情報は、本文だけでなくPropertiesにも入れる。特に `type`、`company`、`status`、`next_action` はBase表示に影響する。
- 事実確認は各社の `企業研究/`、選考で話す内容は企業直下、企業横断の対策は `02_共通対策/` で見る。
