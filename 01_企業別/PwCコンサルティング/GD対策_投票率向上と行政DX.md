# PwC GD対策シート 投票率向上と行政DX

## まず結論

投票率向上のDXは、「ネット投票を導入する」という話に飛ばない方がよい。  
安全な勝ち筋は、投票そのものではなく、投票前の情報探索、投票場所・期日前投票の導線、引越し・住民票異動に伴う手続、若者への接点づくりをデジタルで改善すること。

GDでの勝ち筋は、次の順番で考えること。

```text
対象者を決める
なぜ投票しないのかを分解する
投票コストを下げる施策と、政治を自分事化する施策を分ける
政治的中立性とセキュリティを確認する
短期施策と中長期施策に分けて提案する
```

いきなり「スマホで投票できるようにする」と言わない。  
日本の選挙では本人確認、秘密投票、買収・強制防止、サイバー攻撃、システム信頼性などの論点が重い。  
GDでは「投票行為のオンライン化」より、「投票に行くまでの摩擦を下げるDX」の方が現実的で強い。

## GDで出そうなお題

- 若者の投票率を上げるにはどうしたらよいか。
- 20代の選挙率を向上させるには。
- 投票率を上げるためのデジタル施策を考える。
- 行政サービスの利用率を上げるためのDX施策を考える。
- 若者に政治を自分事として捉えてもらうには。
- 期日前投票の利用を増やすには。
- 地方自治体が若者の政治参加を高める施策を考える。
- 投票所に行く手間を減らすには。
- マイナポータルを活用して行政手続の利便性を高めるには。
- 行政DXによって住民と自治体双方の負担を減らすには。

## 最初に置くべき前提

投票率向上は、全世代を対象にすると広すぎる。  
ワンキャリのお題では若者・20代が多いので、まず対象を絞る。

```text
投票率向上は全世代で考えると広いので、今回は投票率が低くなりやすい若者・20代を対象にしませんか。
ゴールは、短期的には投票に行くまでの手間を減らすこと、中期的には政治を自分事化すること、長期的には投票習慣を作ることに置きたいです。
```

クライアントを置くなら「自治体の選挙管理委員会」か「デジタル庁・自治体連携」。

```text
クライアントを自治体の選挙管理委員会と仮定し、若者の投票参加を高めるデジタル施策として考えたいです。
```

## 基礎ファクト

暗記する数字・事実は以下で十分。

- 2015年6月の公職選挙法改正により、選挙権年齢は20歳以上から18歳以上に引き下げられた。
- 年代別投票率を見ると、一般に若年層は中高年層より低い傾向がある。
- 明るい選挙推進協会は、衆議院選挙などの年代別投票率の推移を公開している。
- 都道府県・市区町村の抽出調査でも、20代の投票率が60代・70代より低い例が多く見られる。
- デジタル庁は、行政手続のオンライン化を進めており、次期オンライン申請サービスでは、一度登録した住所・氏名・家族情報を申請のたびに何度も入力しなくてよいこと、自治体保有情報の転記による住民・職員双方の負担軽減、通知書のオンライン送付などを目指している。
- 引越し手続オンラインサービスでは、マイナポータルから転出届・来庁予定の連絡ができ、転出元市区町村への来庁が原則不要となる。
- 投票率向上施策では、政治的中立性、個人情報保護、公平性、セキュリティが重要。

出典は末尾にまとめる。

## このテーマの本質

### 投票率向上と行政DXの違い

```text
投票率向上:
有権者が投票に行く理由を増やし、投票に行く手間を減らすこと。

行政DX:
住民と行政職員双方の手続負担を下げ、行政サービスをオンライン・ワンストップ・データ連携型に変えること。

投票率向上と行政DX:
選挙に関する情報取得、通知、期日前投票、引越し時の手続、投票所案内などをデジタルで改善し、投票参加のハードルを下げること。
```

GDでは、選挙制度の改革論だけで終わると実行可能性が弱い。  
PwCらしくするなら、自治体業務、住民体験、データ活用、政治的中立性までセットで設計する。

## 投票しない理由の分解

投票率向上は、原因を分解しないと施策が雑になる。

```text
関心がない
争点が分からない
候補者の違いが分からない
自分の一票で変わる実感がない
投票所や投票日を忘れる
投票所が遠い・行く時間がない
引越し後にどこで投票できるか分からない
期日前投票の使い方を知らない
政治や行政への信頼が低い
```

このうち、デジタル施策で直接効くのは主に次の4つ。

- 情報探索コストを下げる。
- 投票行動のリマインドをする。
- 投票場所・期日前投票の導線をよくする。
- 行政手続や住民情報との連携で迷いを減らす。

## 合理的投票者モデルで考える

若者の投票率向上は、次の式で考えると整理しやすい。

```text
投票に行くか = 期待便益 + 市民としての満足感 - 投票コスト
```

もっとGD向けに言うと、

```text
投票したい理由を増やす
投票しない理由を減らす
投票を習慣化する
```

### 投票したい理由を増やす

- 自分の生活に関係する争点が分かる。
- 候補者・政党の違いが分かる。
- 若者世代の投票率が可視化される。
- 投票が社会参加として認知される。

### 投票しない理由を減らす

- 投票日・場所が分かる。
- 期日前投票の方法が分かる。
- 混雑状況が分かる。
- 引越し後の投票可否が分かる。
- 必要な持ち物や手順が分かる。

### 投票を習慣化する

- 初めての選挙で迷わない。
- 学校や大学で実際の争点を中立的に扱う。
- 投票済証や啓発イベントなど、社会的接点を作る。
- 自治体・大学・企業が投票しやすい環境を作る。

## 課題構造

### 1. 情報が分かりにくい

若者が政治に関心がないというより、争点、候補者、政策、投票方法が分かりにくい。  
情報が多すぎる一方で、自分に関係する形に整理されていない。

施策の方向性:

- 中立的な選挙情報ポータル。
- 争点別の候補者比較。
- 自分の関心分野から政策を探せるUI。
- 投票手順の動画・チャットボット。

### 2. 投票に行く手間がある

若者は学業、アルバイト、仕事、引越しなどで生活が流動的。  
投票所や期日前投票の場所・時間を調べる手間が投票率を下げる。

施策の方向性:

- 投票所・期日前投票所マップ。
- 混雑状況表示。
- カレンダー連携リマインド。
- 最寄りの投票所案内。
- 期日前投票の導線強化。

### 3. 引越し・住民票・選挙人名簿が分かりにくい

大学進学や就職で引越す若者は、住民票を移していない、選挙人名簿の登録要件を知らない、どこで投票できるか分からないことがある。

施策の方向性:

- マイナポータルや自治体アプリで選挙人名簿登録状況・投票可能場所を確認できるようにする。
- 引越し手続オンラインサービスと投票案内を接続する。
- 転出・転入時に選挙関連の注意を自動通知する。
- 不在者投票や期日前投票の案内を出す。

### 4. 自分事化しにくい

若者にとって、政策が高齢者や大人向けに見え、自分の生活とつながらないことがある。  
「投票しても変わらない」と感じると、情報提供だけでは動かない。

施策の方向性:

- 学費、奨学金、雇用、住宅、子育て、税・社会保障など、生活接点から争点を見せる。
- 若者世代の投票率と政策反映の関係を可視化する。
- 学校・大学で模擬投票や争点整理を行う。
- SNSではなく、信頼できる公式情報へ誘導する。

### 5. 政治的中立性が難しい

行政や学校が選挙情報を扱うと、特定政党や候補者に偏ってはいけない。  
DX施策も、推薦・誘導に見えると信頼を失う。

施策の方向性:

- 候補者・政党の情報は同じ項目・同じ順序で表示する。
- アルゴリズムの透明性を担保する。
- ランダム表示や届出順など、公平なルールを決める。
- 政策比較は中立的な設問にする。
- 広告ターゲティングではなく、全有権者に公平に通知する。

## 工程で分解する

投票率向上のお題が来たら、有権者行動の工程に分ける。

```text
認知
選挙があることを知る

理解
争点、候補者、政党、投票方法を理解する

意思決定
投票するか、誰に投票するかを決める

準備
投票日、投票所、期日前投票、持ち物を確認する

投票
投票所に行き、投票する

継続
次回も投票する習慣を作る
```

GDでは、すべてを一気に解こうとしない。  
若者投票率なら「認知・理解・準備」に絞るとDX施策が出しやすい。

```text
投票そのものをオンライン化するのは制度・セキュリティの論点が大きいので、今回は投票前の情報取得と期日前投票の導線改善に絞るのが現実的だと思います。
```

## 施策が生まれる思考パターン

### パターン1: 選挙があることを忘れる

課題:

- 投票日を知らない。
- 入場券を見ない。
- SNSで偶然知る。
- 学業・仕事で忘れる。

思考:

```text
予定を忘れるなら、生活導線上で公式リマインドを出す。
```

施策:

- 自治体アプリ・マイナポータル通知。
- カレンダー登録。
- 期日前投票開始日の通知。
- 投票日前日・当日のリマインド。
- 大学・企業ポータルでの中立的告知。

言い方:

```text
若者の投票率向上では、まず選挙情報を生活導線に乗せることが重要です。自治体アプリやマイナポータル、大学ポータルを使って、投票日と期日前投票を公式にリマインドする施策が考えられます。
```

### パターン2: 候補者・争点が分からない

課題:

- 政策の違いが分からない。
- 候補者情報を調べるのが面倒。
- SNS情報は偏りやすい。
- 公式情報が読みにくい。

思考:

```text
情報が多すぎるなら、公式・中立・比較可能な形に整理する。
```

施策:

- 候補者・政党比較ポータル。
- 争点別政策比較。
- 1分で分かる投票方法・争点解説。
- 政策キーワード検索。
- 選挙公報のスマホ最適化。

言い方:

```text
若者に政治への関心がないと決めつけるのではなく、候補者情報が比較しにくいことを課題として捉えるべきです。行政は推薦せず、同じ項目・同じ順序で政策を比較できる公式ポータルを整備するのが有効です。
```

### パターン3: 投票所に行くのが面倒

課題:

- 投票所が分からない。
- 何時まで開いているか分からない。
- 期日前投票を知らない。
- 混雑や待ち時間が不安。

思考:

```text
投票所に行くコストが高いなら、場所・時間・混雑を見える化する。
```

施策:

- 投票所マップ。
- 期日前投票所マップ。
- 現在地からの経路案内。
- 混雑予測・混雑状況。
- 近くの商業施設・駅前期日前投票所の案内。

言い方:

```text
投票率向上では、投票の意思がある人を取りこぼさないことも重要です。期日前投票所の場所、時間、混雑状況をスマホで確認できるようにすれば、投票コストを下げられます。
```

### パターン4: 引越しで投票できる場所が分からない

課題:

- 大学進学・就職で引越す。
- 住民票を移していない。
- 旧住所・新住所どちらで投票できるか分からない。
- 不在者投票の手続が分からない。

思考:

```text
住所変更と選挙手続が関係するなら、引越し手続のタイミングで投票案内を出す。
```

施策:

- 引越し手続オンラインサービスと投票案内の連携。
- 転出・転入時の選挙人名簿登録注意。
- 投票可能自治体の確認。
- 不在者投票手続の案内。
- 大学新入生・新社会人向け通知。

言い方:

```text
若者は進学や就職で住所が変わりやすいので、投票率向上には引越し手続と選挙案内をつなげることが有効です。マイナポータルで転出届を出す導線に、選挙人名簿や不在者投票の案内を組み込むべきです。
```

### パターン5: 政治を自分事化できない

課題:

- 政策が自分の生活に関係している実感がない。
- 政治は遠いものに見える。
- 投票しても変わらないと思う。

思考:

```text
抽象的な政治ではなく、生活課題から争点に入る。
```

施策:

- 「学費」「奨学金」「雇用」「家賃」「税金」「社会保障」など生活テーマ別の争点整理。
- 若者向け政策比較。
- 模擬投票。
- 自治体予算の見える化。
- 自分の地域の課題ダッシュボード。

言い方:

```text
投票率を上げるには、候補者名を覚えてもらうより、まず政治が自分の生活に関係していると感じてもらう必要があります。学費、雇用、住宅、税金など生活テーマから政策を見られる仕組みが有効です。
```

## 主要施策カード

### 施策1: 若者向け選挙参加ポータル

向いている課題:

- 選挙情報が分散している。
- 候補者・政党の比較が難しい。
- 投票方法が分からない。
- 若者が公式情報に触れない。

施策内容:

- 自治体選管が公式ポータルを作る。
- 投票日、期日前投票、投票所、持ち物を表示する。
- 候補者・政党情報を同じ項目で比較する。
- 争点別に政策を検索できるようにする。
- カレンダー登録や通知機能をつける。

なぜ生まれるか:

若者が投票しない理由を「関心がない」で止めると施策が啓発ポスターになる。  
実際には、情報が分散し、比較しにくく、投票の手順も分かりにくい。  
公式・中立・スマホ最適化された導線を作ることで、情報探索コストを下げられる。

効果:

- 投票方法の理解向上。
- 候補者情報の比較促進。
- 投票忘れ防止。
- SNSの不確かな情報への依存低下。

KPI:

- ポータル訪問数。
- 期日前投票ページ閲覧数。
- カレンダー登録数。
- 投票所検索数。
- 若年層の投票率。
- ユーザー満足度。

注意点:

- 政治的中立性。
- 候補者表示順。
- 情報更新の正確性。
- アクセシビリティ。
- 個人情報を取りすぎない。

GDでの使い方:

```text
若者向けには、SNS広告よりも、公式で中立的な選挙参加ポータルが必要だと思います。投票日、期日前投票、候補者比較、投票所検索をスマホで一つにまとめ、情報探索コストを下げます。
```

### 施策2: 期日前投票導線のDX

向いている課題:

- 投票日に予定がある。
- 期日前投票を知らない。
- 期日前投票所の場所・時間が分からない。
- 駅前や商業施設の投票所を活用できていない。

施策内容:

- 期日前投票所マップを提供する。
- 現在地から近い投票所を案内する。
- 開設時間・混雑状況を表示する。
- カレンダー連携でリマインドする。
- 大学・駅・商業施設近くの投票所を重点案内する。

なぜ生まれるか:

投票日に行けない人でも、期日前投票なら投票できる。  
しかし制度を知らない、場所が分からない、時間が分からない人は取りこぼされる。  
投票意思がある層を逃さない施策として効果が出やすい。

効果:

- 投票機会の拡大。
- 投票日の混雑緩和。
- 若者・働く世代の参加促進。
- 投票忘れ防止。

KPI:

- 期日前投票利用率。
- 期日前投票所検索数。
- 通知開封率。
- 若者の投票率。
- 投票日当日の混雑。

注意点:

- 混雑情報の取得方法。
- 高齢者やスマホ非利用者への代替手段。
- 特定地域だけ有利にならない公平性。

GDでの使い方:

```text
短期で投票率に効きやすいのは、オンライン投票ではなく期日前投票の導線改善だと思います。場所、時間、混雑、経路をスマホで分かるようにすれば、投票意思がある人の取りこぼしを減らせます。
```

### 施策3: 引越し手続と選挙案内の連携

向いている課題:

- 進学・就職で住所が変わる若者。
- 住民票を移していない。
- どこで投票できるか分からない。
- 不在者投票を知らない。

施策内容:

- マイナポータルの引越し手続時に、選挙人名簿登録や投票可能場所の注意を表示する。
- 転出・転入予定者に、次回選挙での投票方法を案内する。
- 不在者投票の手続ページへ誘導する。
- 大学・企業の新生活支援サイトと連携する。

なぜ生まれるか:

若者の投票率低下には、関心だけでなく生活移動の問題がある。  
引越しは行政手続の接点なので、このタイミングで投票に関する迷いを減らせる。

効果:

- 投票可能場所の認知向上。
- 不在者投票の利用促進。
- 住民票異動の理解促進。
- 初めての選挙での離脱防止。

KPI:

- 引越し手続時の選挙案内閲覧数。

```text
私は、若者向けの選挙参加ポータルを提案します。
若者の投票率が低い理由は、政治への関心だけでなく、候補者情報が分かりにくい、投票所や期日前投票の情報が届かないという投票コストにもあると思います。
そこで、自治体公式のスマホ向けポータルで、投票日、投票所、期日前投票、候補者情報を一元化し、カレンダー通知も行います。
候補者情報は同じ項目で表示し、行政が推薦しないことで中立性を守ります。
```

### デジタル施策を聞かれたら

```text
投票率向上のデジタル施策としては、ネット投票よりも、まず投票前の導線改善が現実的です。
具体的には、投票所・期日前投票所のマップ、混雑状況、カレンダー通知、候補者情報比較を公式ポータルで提供します。
これにより、投票に行く意思はあるが、場所や時間が分からず離脱している層を取り込めます。
```

### ネット投票を聞かれたら

```text
ネット投票は利便性が高い一方で、本人確認、秘密投票、買収・強制防止、サイバー攻撃対策などの論点が大きいです。
そのため、短期的には投票行為そのものではなく、投票前の情報取得、期日前投票導線、引越し時の投票案内をDXする方が現実的だと考えます。
```
