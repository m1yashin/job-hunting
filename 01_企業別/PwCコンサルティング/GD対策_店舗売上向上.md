# PwC GD対策シート 身近な店舗の売上向上

## まず結論

店舗売上向上は、どの業界でもまず次の式に戻す。

```text
売上 = 客数 × 客単価 × 来店頻度
利益 = 売上 - 変動費 - 固定費
```

GDで強い答えは、売上だけでなく利益と実行可能性まで見ること。  
「SNSで集客」「キャンペーンを打つ」で終わらせず、顧客データ、予約・会員化、在庫・人員最適化、顧客体験改善まで入れる。

```text
誰を増やすか
なぜ来ないか
何を買わせるか
どう再来店させるか
現場で回るか
利益が残るか
```

## GDで出そうなお題

- 映画館の1日の来場者数向上。
- フィットネスジムの売上向上。
- 薬局の売上向上。
- コンビニの売上向上。
- スーパーマーケットの売上を上げるには。
- 花屋の売上を上げるには。
- 日本におけるネイルサロンの成長戦略・市場拡大。
- 日本における美容室の成長戦略。
- 登録者数を増やすには。
- ラグジュアリーホテルの利用者数を増加させるには。
- ある業界の市場を拡大させる施策。
- IT技術を用いた売上向上策。

## 最初に置くべき前提

店舗売上向上は、対象店舗とKPIを決めないと発散する。

```text
売上向上は広いので、まず売上を客数、客単価、来店頻度に分解したいです。
今回は短期で効果が出やすい客数増加と、中期で効く会員化・再来店促進に絞りませんか。
```

業界が指定されていない場合は、身近で議論しやすい「駅前の中規模店舗」などに置く。

```text
今回は駅前の中規模店舗を想定し、既存顧客の再来店と、平日昼など空いている時間帯の集客を増やす方向で考えたいです。
```

PwCらしくするなら、

```text
単なる販促ではなく、POS・会員データ・予約データを使って、顧客セグメント別に施策を分けたいです。
```

## 基礎ファクト

暗記する事実は以下で十分。

- 経済産業省は商業動態統計を公表しており、小売業・卸売業の販売動向を把握できる。
- 経済産業省によると、2025年のキャッシュレス決済比率は58.0%となった。2024年の42.8%から上昇している。
- キャッシュレス化は、顧客利便性だけでなく、購買データの取得、レジ業務効率化、会員連携につながる。
- 観光庁はインバウンド消費動向調査を公表しており、訪日外国人消費は小売・飲食・宿泊・交通などの売上向上テーマと接続しやすい。
- 店舗DXでは、POS、会員アプリ、予約、モバイルオーダー、キャッシュレス、在庫管理、シフト最適化、CRMが基本施策になる。

出典は末尾にまとめる。

## このテーマの本質

### 売上向上と利益向上の違い

```text
売上向上:
客数、客単価、来店頻度を上げること。

利益向上:
売上を上げつつ、値引き、広告費、人件費、在庫ロスを管理すること。
```

GDでは売上だけ上げる施策は危ない。  
たとえば大幅値引きは客数を増やすが、利益を削る。  
PwCらしくするなら、売上KPIと利益KPIを両方置く。

## 売上分解

### 基本式

```text
売上 = 客数 × 客単価 × 来店頻度
```

### 客数を増やす

- 新規顧客獲得。
- 休眠顧客復活。
- 平日昼・雨の日・閑散時間の集客。
- 観光客・インバウンド獲得。
- 周辺施設との連携。

### 客単価を上げる

- セット販売。
- アップセル。
- クロスセル。
- 高付加価値商品。
- サブスク・会員プラン。
- ギフト需要。

### 来店頻度を上げる

- 会員アプリ。
- ポイント。
- 定期購入。
- 予約。
- リマインド。
- パーソナライズクーポン。

### 利益を守る

- 値引き依存を避ける。
- 在庫ロスを減らす。
- シフトを最適化する。
- 広告費を効果測定する。
- 高粗利商品の販売比率を上げる。

## 課題構造

### 1. 顧客が誰か分かっていない

「売上を上げる」と言っても、誰を増やすのかで施策が変わる。  
学生、会社員、ファミリー、高齢者、観光客、既存顧客、休眠顧客で刺さる施策は違う。

施策の方向性:

- POS・会員データ分析。
- 顧客セグメント。
- 購買頻度分析。
- RFM分析。
- ペルソナ設定。

### 2. 閑散時間がある

店舗には、平日昼、雨の日、早朝、夜、シーズンオフなど、空いている時間がある。  
全体集客より、空き時間を埋める施策の方が利益に効きやすい。

施策の方向性:

- 時間帯別クーポン。
- 平日限定プラン。
- 予約枠最適化。
- 需要予測。
- シフト最適化。

### 3. 再来店につながっていない

新規顧客を広告で集めても、再来店しなければ費用対効果が悪い。  
会員化とCRMが重要。

施策の方向性:

- 会員アプリ。
- ポイント。
- 来店リマインド。
- 誕生日クーポン。
- 購買履歴に基づくおすすめ。

### 4. 客単価が伸びない

単品購入や低価格商品に偏ると売上が伸びにくい。  
セット化、関連商品、体験価値、ギフト化が効く。

施策の方向性:

- セット販売。
- 高粗利商品の配置。
- レコメンド。
- サブスク。
- プレミアムプラン。

### 5. オペレーションが追いつかない

集客しても、レジ待ち、スタッフ不足、在庫切れ、予約管理ミスが起きると逆効果。  
売上施策と店舗運営はセットで考える。

施策の方向性:

- モバイルオーダー。
- セルフレジ。
- キャッシュレス。
- 在庫管理。
- シフト最適化。
- 予約管理。

### 6. デジタル施策が点で終わる

アプリ、POS、SNS、予約、ECがバラバラだと、顧客理解につながらない。  
データをつなぐことが必要。

施策の方向性:

- CRM統合。
- 会員ID統合。
- POS連携。
- オンラインと店舗の統合。
- 顧客ダッシュボード。

## 店舗業務で分解する

店舗売上向上のお題が来たら、工程に分ける。

```text
認知
SNS、検索、地図、口コミ、チラシ、紹介

来店前
予約、在庫確認、クーポン、経路、混雑情報

来店
接客、陳列、待ち時間、店内体験

購買
商品選択、セット提案、決済、ポイント

来店後
レビュー、再来店通知、会員化、レコメンド

運営
発注、在庫、シフト、レジ、清掃、売上分析
```

GDでは一番効く工程を選ぶ。

```text
今回は新規集客より、既存顧客の再来店と客単価向上に絞る方が、広告費を抑えながら売上を伸ばしやすいと思います。
```

## 施策が生まれる思考パターン

### パターン1: 客数が少ない

課題:

- 認知されていない。
- 店舗前を通る人が入らない。
- 競合に流れている。
- 閑散時間がある。

思考:

```text
客数が少ないなら、新規集客、休眠復活、閑散時間集客に分ける。
```

施策:

- Googleマップ・口コミ改善。
- SNS・地域広告。
- 平日限定クーポン。
- 周辺施設連携。
- 紹介キャンペーン。
- インバウンド対応。

言い方:

```text
客数増加は、単に広告を打つのではなく、新規顧客、休眠顧客、閑散時間のどこを狙うかを分けるべきです。
```

### パターン2: 客単価が低い

課題:

- 単品購入が多い。
- 高粗利商品が売れない。
- 関連商品を提案できていない。

思考:

```text
客単価が低いなら、買う理由があるセットと高付加価値商品を作る。
```

施策:

- セット販売。
- アップセル。
- クロスセル。
- ギフト化。
- プレミアムプラン。
- レコメンド。

言い方:

```text
客単価向上では、無理に高い商品を売るのではなく、顧客の目的に合わせてセット化や関連商品提案を行うべきです。
```

### パターン3: 再来店しない

課題:

- 一度来ても忘れられる。
- 会員化できていない。
- 次回来店理由がない。

思考:

```text
再来店が少ないなら、購入後の接点を作る。
```

施策:

- 会員アプリ。
- ポイント。
- 来店リマインド。
- 誕生日・記念日クーポン。
- 定期購入。
- レビュー依頼。

言い方:

```text
広告で新規顧客を集めるより、既存顧客の再来店を増やす方が費用対効果が高い場合があります。会員化と購入後の接点づくりが重要です。
```

### パターン4: 店舗運営が非効率

課題:

- レジ待ち。
- スタッフ不足。
- 在庫切れ。
- 発注ミス。
- シフトが合わない。

思考:

```text
売上機会を逃しているなら、店舗オペレーションをDXする。
```

施策:

- セルフレジ。
- モバイルオーダー。
- キャッシュレス。
- 在庫管理。
- 需要予測。
- シフト最適化。

言い方:

```text
売上向上は販促だけではなく、レジ待ちや在庫切れなど、購入機会を失うオペレーション課題を解くことも重要です。
```

### パターン5: 業界が成熟している

課題:

- 類似店舗が多い。
- 価格競争。
- 市場成長が鈍い。
- 差別化しにくい。

思考:

```text
成熟市場では、新規顧客より体験価値・専門性・会員化で差別化する。
```

施策:

- 専門相談。
- 体験イベント。
- サブスク。
- パーソナライズ。
- 高付加価値メニュー。
- コミュニティ化。

言い方:

```text
成熟市場では価格競争に寄せるより、体験価値や専門性を高め、継続利用につなげる方が利益を残しやすいです。
```

## 主要施策カード

### 施策1: POS・会員データ分析

向いている課題:

- 顧客が見えていない。
- 売れ筋が分からない。
- 施策の効果測定ができない。
- 店長の勘に依存。

施策内容:

- POS、会員、予約、ECデータを統合する。
- 顧客を新規、既存、休眠、高頻度に分ける。
- 商品別、時間帯別、顧客別の売上を分析する。
- 施策別の効果を測る。

なぜ生まれるか:

店舗施策は、誰に何を売るかが見えないと当たらない。  
POSと会員データがあれば、売上分解と顧客セグメントができる。

効果:

- 施策の精度向上。
- 顧客別アプローチ。
- 売れ筋把握。
- 在庫・シフト最適化。

KPI:

- 会員化率。
- 顧客セグメント別売上。
- 施策反応率。
- リピート率。
- 粗利率。

注意点:

- 個人情報。
- 会員登録の手間。
- データが散らばる。
- 分析して終わらせない。

GDでの使い方:

```text
店舗売上向上では、まずPOS・会員データで、誰が、いつ、何を、どれくらい買っているかを可視化するべきです。そこから客数、客単価、来店頻度のどこに課題があるかを見ます。
```

### 施策2: 会員アプリ・CRM

向いている課題:

- 再来店しない。
- 顧客接点がない。
- クーポンが一律。
- 休眠顧客が多い。

施策内容:

- 会員アプリを導入する。
- 購買履歴に応じてクーポンを出す。
- 来店リマインドを送る。
- ポイントやランク制度を作る。
- 休眠顧客向け復活施策を打つ。

なぜ生まれるか:

新規集客は広告費がかかる。  
既存顧客の来店頻度を上げる方が費用対効果が高いことが多い。

効果:

- 再来店増。
- 客単価向上。
- 顧客理解。
- 口コミ促進。

KPI:

- アプリ登録率。
- リピート率。
- 来店頻度。
- クーポン利用率。
- 休眠復活率。

注意点:

- 通知過多。
- クーポン依存。
- アプリ登録のハードル。
- 高齢者対応。

GDでの使い方:

```text
再来店を増やすには、会員アプリで購入後の接点を作ることが有効です。ただし一律クーポンではなく、購買履歴に応じて提案を変えるべきです。
```

### 施策3: 閑散時間の需要創出

向いている課題:

- 平日昼が空いている。
- 雨の日に客が減る。
- スタッフや設備が遊んでいる。
- ピーク時だけ混む。

施策内容:

- 時間帯別クーポン。
- 平日限定メニュー。
- 予約割。
- 雨の日特典。
- シニア・学生向け時間帯プラン。

なぜ生まれるか:

ピーク時の集客を増やしても、席数や人員で限界がある。  
空いている時間帯を埋めれば、追加コストを抑えて売上を伸ばせる。

効果:

- 稼働率向上。
- 売上平準化。
- スタッフ効率向上。
- 顧客満足度向上。

KPI:

- 時間帯別客数。
- 稼働率。
- 平日売上。
- クーポン利用率。
- 人時売上。

注意点:

- 値引きしすぎ。
- 既存客の値引き移行。
- オペレーション負荷。

GDでの使い方:

```text
売上向上では、ピークをさらに増やすより、平日昼や雨の日など空いている時間帯を埋める方が利益に効きやすいです。
```

### 施策4: セット販売・アップセル

向いている課題:

- 客単価が低い。
- 単品購入が多い。
- 高粗利商品が売れない。
- 購入目的が明確。

施策内容:

- セットメニューを作る。
- 関連商品を提案する。
- プレミアムプランを用意する。
- ギフトセットを作る。
- レジ・アプリでレコメンドする。

なぜ生まれるか:

顧客は目的を持って来店する。  
その目的に沿った関連商品や上位体験を提案すれば、無理なく客単価を上げられる。

効果:

- 客単価向上。
- 粗利率向上。
- 顧客満足度向上。
- 在庫回転改善。

KPI:

- 客単価。
- セット購入率。
- 高粗利商品販売比率。
- 粗利額。
- レコメンドクリック率。

注意点:

- 押し売りに見えないこと。
- セット割で粗利を落としすぎない。
- 顧客ニーズに合う組み合わせ。

GDでの使い方:

```text
客単価を上げるなら、単純な値上げではなく、顧客の利用目的に合わせたセット販売や関連商品提案が有効です。
```

### 施策5: 予約・モバイルオーダー・待ち時間削減

向いている課題:

- 待ち時間が長い。
- レジ行列。
- 回転率が低い。
- 予約管理がアナログ。

施策内容:

- 予約システムを導入する。
- モバイルオーダーを導入する。
- 事前決済を使う。
- 混雑状況を表示する。
- 来店時間を分散する。

なぜ生まれるか:

顧客は待ち時間が長いと離脱する。  
予約・事前注文・事前決済により、顧客体験と店舗回転率を同時に改善できる。

効果:

- 待ち時間削減。
- 回転率向上。
- 客数増。
- スタッフ負担軽減。

KPI:

- 待ち時間。
- 回転率。
- 予約数。
- モバイルオーダー率。
- 離脱率。

注意点:

- 高齢者対応。
- 注文ミス。
- ピーク集中。
- 導入コスト。

GDでの使い方:

```text
来店客を増やしても待ち時間が長いと離脱します。予約やモバイルオーダーで待ち時間を減らし、回転率を上げることも売上向上策です。
```

### 施策6: キャッシュレス・セルフレジ

向いている課題:

- レジ待ち。
- 人手不足。
- 現金管理コスト。
- 購買データが取れない。

施策内容:

- キャッシュレス決済を拡充する。
- セルフレジ・セミセルフレジを導入する。
- 会員IDと決済を連携する。
- レジデータをPOS分析に使う。

なぜ生まれるか:

キャッシュレスは支払いの利便性だけでなく、レジ時間削減、現金管理削減、購買データ取得につながる。

効果:

- レジ待ち削減。
- 人件費効率化。
- 購買データ取得。
- 顧客利便性向上。

KPI:

- キャッシュレス比率。
- レジ待ち時間。
- レジ人時。
- 会員ID連携率。
- 決済エラー件数。

注意点:

- 高齢者・現金派。
- 手数料。
- 操作支援。
- 万引き対策。

GDでの使い方:

```text
キャッシュレスやセルフレジは、単に支払いを便利にするだけでなく、レジ待ち削減と購買データ取得につながるため、売上向上の土台になります。
```

### 施策7: インバウンド対応

向いている課題:

- 観光地店舗。
- ホテル・飲食・小売。
- 外国人客が入店しにくい。
- 言語・決済・商品説明の壁。

施策内容:

- 多言語メニュー・POP。
- 海外決済対応。
- 免税・配送対応。

## 施策評価軸

GDで施策を比較するときは、この6つを使う。

```text
売上効果:
客数、客単価、来店頻度のどれに効くか。

利益効果:
値引きや広告費を差し引いて利益が残るか。

実現性:
既存データ・現場オペレーションで実行できるか。

顧客体験:
便利さ、待ち時間、楽しさ、納得感が上がるか。

継続性:
一回限りのキャンペーンでなく、再来店につながるか。

データ活用:
次の施策改善につながるデータが取れるか。
```

発言例:

```text
施策を客数、客単価、来店頻度のどこに効くかで整理すると、広告は客数、セット販売は客単価、会員アプリは来店頻度に効きます。
```

```text
値引き施策は客数を増やせますが、利益を削る可能性があるので、閑散時間や期限近商品に限定するべきです。
```

## ありがちな失敗

### 失敗1: SNSで集客だけ

悪い例:

```text
SNSで宣伝します。
```

改善:

```text
SNSは認知には有効ですが、来店、購買、再来店につながる導線が必要です。予約、クーポン、会員化、口コミまで設計すべきです。
```

### 失敗2: 値引きだけ

悪い例:

```text
値下げすれば客が増えます。
```

改善:

```text
値引きは粗利を削るため、閑散時間や期限近商品など、追加売上が利益に残る場面に限定すべきです。
```

### 失敗3: 客数だけ見る

悪い例:

```text
来店客を増やします。
```

改善:

```text
売上は客数、客単価、来店頻度なので、どこを上げる施策かを明確にする必要があります。
```

### 失敗4: 現場負担を無視する

悪い例:

```text
スタッフにおすすめ商品を毎回提案してもらいます。
```

改善:

```text
現場負担が増えると続かないため、レコメンド表示、セット設計、POP、アプリ通知など仕組みで補うべきです。
```

### 失敗5: データを取って終わる

悪い例:

```text
POSデータを分析します。
```

改善:

```text
分析結果を、発注、陳列、クーポン、シフト、商品開発に反映して初めて価値が出ます。
```
