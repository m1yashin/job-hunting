# 企業長期展望リサーチ依頼テンプレ

```text
Use $company-longterm-research.
goalを開始してください。

対象企業:
- 企業名

目的:
企業名について、経営面的展望と技術面的展望の両方から、中長期の事業変化・技術変化・開発方法の変化・求められる人材像を明らかにする。
最終的には、公式資料ベースで高品質な長期展望レポートを作成できる状態にする。

重要方針:
- いきなり最終レポートを書かない。
- まず資料収集を最優先する。
- 公式情報、IR、統合報告書、中期経営計画、有価証券報告書、技術レポート、R&D資料、採用ページ、職種紹介、人的資本資料、プレスリリース、役員インタビューを優先する。
- 口コミ、SNS、掲示板は使う場合も参考情報に分け、事実根拠にしない。
- すべての情報に確認日と出典URLを残す。
- 事実、解釈、仮説、要確認を分ける。

進め方:
1. 資料候補を可能な限り収集し、Source Indexを作る。
2. 重要資料をS/A/B/Cで優先度付けする。
3. 重要資料から順にSource Noteを作る。
4. Source Noteを横断して、経営視点・技術視点・人材像の論点マップを作る。
5. 十分な根拠が揃ってから、1万字以上の長期展望レポートを作る。
6. 最後に、事実は企業研究へ、選考で使う見立ては選考対策へ切り出す。

品質基準:
- 最終レポートは、最低10本以上のSource Noteを根拠にする。
- 経営資料だけ、技術資料だけに偏らない。
- 経営視点と技術視点を必ず接続する。
- 「この会社はどんな未来を見ているか」「そのためにどんな技術を伸ばすか」「その結果どんな人材が必要か」を一貫して説明する。
- 断定できない内容は仮説または要確認にする。
```
