# 99_Templates/AGENTS.md

## 目的

このフォルダには、現在のシンプル構成で繰り返し使うノート雛形を置く。

## 使い方

- 企業基本ノートは `企業ノートテンプレ.md` を `02_Companies/企業名/企業概要.md` にコピーする。
- ES一覧は `ES一覧テンプレ.md` を `02_Companies/企業名/ES/ES一覧.md` にコピーする。
- 企業分析は `企業分析テンプレ.md` を `02_Companies/企業名/企業分析.md` にコピーする。
- 素材要約は `素材要約テンプレ.md` を `02_Companies/企業名/素材要約.md` にコピーする。
- 企業別面接対策は `企業別面接対策テンプレ.md` を `02_Companies/企業名/面接対策.md` にコピーする。
- ES設問は `ES設問テンプレ.md` を `02_Companies/企業名/ES/設問種別_字数.md` にコピーする。
- 面接質問Itemは `面接質問Itemテンプレ.md` を `01_Selection/面接/質問/個別質問/質問名.md` にコピーする。
- 回答ユニットは `回答ユニットテンプレ.md` を `01_Selection/面接/回答ユニット/回答名.md` にコピーする。
- 面接ログは `面接ログテンプレ.md` を `02_Companies/企業名/ログ/YYYY-MM-DD_企業名_面接名.md` にコピーする。
- GDフレームは `GDフレームテンプレ.md` を `01_Selection/グループディスカッション/型/フレーム名.md` にコピーする。
- GD復習ログは `GD復習ログテンプレ.md` を `02_Companies/企業名/ログ/YYYY-MM-DD_企業名_GD復習.md` にコピーする。
- WebClip整理は `WebClip整理テンプレ.md` を `03_メモ素材/WebClip/業界/企業/YYYY-MM-DD_資料名.md` にコピーする。
- 素材メモは `素材メモテンプレ.md` を `03_メモ素材/草案/`、`03_メモ素材/母艦/`、または `03_メモ素材/思考メモ/` にコピーする。

## 編集ルール

- テンプレート内のPropertiesキー名は、各フォルダのAGENTS.mdと揃える。
- `status` は進捗判断に使うテンプレートだけに入れる。質問、企業分析、素材要約、ログ、GDフレームには入れない。
- 使わない独立カテゴリ用テンプレートは増やさない。
- 未確定情報をテンプレート内で断定しない。
