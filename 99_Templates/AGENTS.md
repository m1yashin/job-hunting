# 99_Templates/AGENTS.md

## 文字コード

このファイルとこのフォルダ配下のMarkdownファイルは、文字化けを防ぐためUTF-8で開く。

## 目的

このフォルダには、現在の構成で繰り返し使うノート雛形を置く。

## 使い方

- 業界研究は `業界研究テンプレ.md` を `02_企業研究/業界研究/業界名.md` にコピーする。
- 企業比較は `企業比較テンプレ.md` を `02_企業研究/企業比較/業界名_主要企業比較.md` にコピーする。
- 企業概要は `企業概要テンプレ.md` を `02_企業研究/企業別/企業名/企業概要.md` にコピーする。
- 事業分析は `事業分析テンプレ.md` を `02_企業研究/企業別/企業名/事業分析.md` にコピーする。
- 中期経営計画要約は `中期経営計画要約テンプレ.md` を `02_企業研究/企業別/企業名/中期経営計画要約.md` にコピーする。
- 競合比較は `競合比較テンプレ.md` を `02_企業研究/企業別/企業名/競合比較.md` にコピーする。
- 採用情報は `採用情報テンプレ.md` を `02_企業研究/企業別/企業名/採用情報.md` にコピーする。
- 最近のニュースは `最近のニューステンプレ.md` を `02_企業研究/企業別/企業名/最近のニュース.md` にコピーする。
- 出典は `出典テンプレ.md` を `02_企業研究/企業別/企業名/出典.md` にコピーする。
- 選考サマリーは `選考サマリーテンプレ.md` を `01_選考対策/企業名/選考サマリー.md` にコピーする。
- 志望理由は `志望理由テンプレ.md` を `01_選考対策/企業名/志望理由.md` にコピーする。
- 逆質問は `逆質問テンプレ.md` を `01_選考対策/企業名/逆質問.md` にコピーする。
- 選考用の競合差別化は `選考_競合差別化テンプレ.md` を `01_選考対策/企業名/競合差別化.md` にコピーする。
- ES一覧は `ES一覧テンプレ.md` を `01_選考対策/企業名/ES.md` にコピーする。
- ES設問は `ES設問テンプレ.md` を `01_選考対策/企業名/ES.md`、または設問が多い場合は `01_選考対策/企業名/ES/設問種別_字数.md` にコピーする。
- 企業別面接対策は `企業別面接対策テンプレ.md` を `01_選考対策/企業名/面接対策.md` にコピーする。
- 面接質問Itemは `面接質問Itemテンプレ.md` を `01_選考対策/共通_面接/質問/個別質問/質問名.md` にコピーする。
- 回答ユニットは `回答ユニットテンプレ.md` を `01_選考対策/共通_面接/回答ユニット/回答名.md` にコピーする。
- 面接ログは `面接ログテンプレ.md` を `01_選考対策/企業名/ログ/YYYY-MM-DD_面接名.md` にコピーする。
- GDフレームは `GDフレームテンプレ.md` を `01_選考対策/共通_GD/型/フレーム名.md` にコピーする。
- GD復習ログは `GD復習ログテンプレ.md` を `01_選考対策/企業名/ログ/YYYY-MM-DD_GD復習.md` にコピーする。
- WebClip整理は `WebClip整理テンプレ.md` を `03_メモ素材/WebClip/業界/企業/YYYY-MM-DD_資料名.md` にコピーする。
- ワンキャリ質問抽出リストは `ワンキャリ質問抽出リストテンプレ.md` を `03_メモ素材/WebClip/企業名_選考段階_抽出質問リスト.md` にコピーする。
- 素材メモは `素材メモテンプレ.md` を `03_メモ素材/草案/`、`03_メモ素材/母艦/`、または `03_メモ素材/思考メモ/` にコピーする。

## 編集ルール

- テンプレート内のPropertiesキー名は、各フォルダのAGENTS.mdと揃える。
- `02_企業研究/` 用テンプレートには、自分との接点、志望理由、面接論点、逆質問候補を入れない。
- `01_選考対策/企業名/` 用テンプレートには、企業研究の長い本文を貼らず、必要に応じて `02_企業研究/` へのリンクを置く。
- `status` は進捗判断に使うテンプレートだけに入れる。質問、企業研究、素材要約、ログ、GDフレームには原則として入れない。
- 未確定情報をテンプレート内で断定しない。
