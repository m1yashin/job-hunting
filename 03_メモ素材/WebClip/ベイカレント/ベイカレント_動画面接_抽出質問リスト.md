# ベイカレント 動画面接 抽出質問リスト

## 前提

ワンキャリの27年卒・26年卒体験談から、動画面接・録画面接・動画選考に該当する質問だけを整理した。質問文は面接官に聞かれる形に整え、同じ意味のものは統合した。

## 最優先で準備する質問

1. 自己PRをしてください。
2. あなたの強みと、それを発揮した具体的な経験を教えてください。
3. 志望動機を教えてください。
4. なぜコンサルティング業界を志望しているのですか。
5. なぜベイカレントを志望しているのですか。
6. なぜシステムコンサルタント職を志望しているのですか。
7. 学生時代に力を入れたことを教えてください。
8. 研究内容、または大学で取り組んだことを簡潔に教えてください。

## カテゴリ別 質問リスト

### 自己PR・強み

- 自己PRをしてください。
- あなたの強みを教えてください。
- その強みが発揮された経験を教えてください。
- 学生時代に頑張ったことや自分の強みを含めて、30秒から60秒程度で自己紹介してください。

### 志望動機

- 志望動機を教えてください。
- なぜベイカレントを志望しているのですか。
- ベイカレントでどのようなことを実現したいですか。
- 将来やりたいことを教えてください。

### 職種理解

- なぜコンサルティング業界を志望しているのですか。
- なぜシステムコンサルタント職を志望しているのですか。
- ITとビジネスの両面から企業を支援することに、なぜ興味があるのですか。

### ガクチカ・研究・活動経験

- 学生時代に力を入れたことを教えてください。
- 研究活動で取り組んだ内容を教えてください。
- サークル活動や課外活動から得た力を教えてください。
- これまでの経験の中で、周囲と協力して成果を出した経験を教えてください。

### 基本確認

- 氏名を教えてください。
- 大学名と名前を含めて、簡潔に自己紹介してください。

## 体験談ごとの質問パターン

### 27年卒 システムコンサルタント職

- 自己PR + 志望動機
- 自己PR + 志望動機 + 将来やりたいこと
- 氏名 + ガクチカ + 研究内容 + サークル活動で得た力 + ベイカレント志望理由 + なぜシステムコンサルタント職か

### 27年卒 コンサルタント職

- 自己PRのみ
- 自己PR + 志望動機

### 26年卒 システムコンサルタント職

- 自己PR + 志望動機
- 1分程度の動画を2本。自己PR・志望動機など一般的な動画選考の設問
- 26年卒コンサルタント職の選考ステップ上では、自己PR・ガクチカ・強み系の1問
