# 大和総研 夏インターン面接 抽出質問リスト

## 前提

- 確認できた27卒ITソリューション系夏インターン選考では、面接は見当たらない。
- 以下は、夏インターン参加後・経由の本選考面接や面談で出ている質問を、夏インターン後の面接対策にも使える形へ正規化したもの。
- 質問だけを載せる。回答例や体験談本文は載せない。

## 最優先で準備する質問

1. 自己紹介と志望動機を2-3分で説明してください。
2. 自己紹介と自己PRを3分程度で説明してください。
3. 大和総研を志望する理由を教えてください。
4. 大学での研究内容を、専門外の人にもわかるように説明してください。
5. 学生時代に力を入れたことについて教えてください。
6. インターンではどのようなことに取り組みましたか。
7. インターンのチームで、あなたはどのような役割を担いましたか。
8. なぜ金融システムや金融領域に興味を持っていますか。
9. IT業界の中で、どの領域や会社を見ていますか。
10. PMにとって大事なことは何だと思いますか。
11. 将来、大和総研のプロジェクトでどのような役割を担いたいですか。
12. 最近気になるニュースと、それに対する考えを教えてください。

## カテゴリ別 質問リスト

### 自己紹介・志望動機

1. 自己紹介と志望動機を2-3分で説明してください。
2. 自己紹介と自己PRを3分程度で説明してください。
3. 大和総研を志望する理由を教えてください。
4. なぜ金融システムや金融領域に興味を持っていますか。
5. なぜ内販に関心があるのですか。
6. IT業界の中で、どの領域や会社を見ていますか。
7. 他社と比べて、大和総研はどのような会社に見えていますか。

### 研究・ガクチカ・経験深掘り

1. 大学での研究内容を、専門外の人にもわかるように説明してください。
2. 研究内容について、工夫した点や難しかった点を教えてください。
3. 学生時代に力を入れたことについて教えてください。
4. 学生時代に力を入れたことについて、具体的に深掘りさせてください。
5. アルバイトではどのようなことを学びましたか。
6. これまでの失敗・挫折経験について教えてください。
7. 困難や課題に直面したとき、どのように対処しましたか。

### 強み・人物理解

1. 自分の強みを、大和総研でどのように活かせると思いますか。
2. 周囲からどのようなキャラクターだと言われますか。
3. キャッチアップが早い方だと思いますか。
4. なぜキャッチアップが早いと感じたのですか。
5. リーダーとして大切にしていることは何ですか。
6. 普段から調整役に回ることが多いですか。
7. どのような社会人になりたいですか。

### インターン・業務理解

1. インターンではどのようなことに取り組みましたか。
2. インターンのチームで、あなたはどのような役割を担いましたか。
3. インターンを通じて、大和総研の印象はどう変わりましたか。
4. インターンを通じて、内販と外販をどのように捉えましたか。
5. PMにとって大事なことは何だと思いますか。
6. 将来、大和総研のプロジェクトでどのような役割を担いたいですか。
7. SIerとして重要な視点は何だと思いますか。
8. 入社後に取り組みたい仕事は何ですか。

### 業界理解・キャリア

1. IT業界の中で、どの領域や会社を見ていますか。
2. 金融に興味を持っている理由を教えてください。
3. 金融システムのどのような点に関心がありますか。
4. 他の志望企業と、その理由を教えてください。
5. 海外での仕事に興味はありますか。
6. 今後のIT業界や大和総研の展望について、どのように考えていますか。

### 役員面接・応用質問

1. 最近気になるニュースと、それに対する考えを教えてください。
2. そのニュースについて、もう少し詳しく考えを聞かせてください。
3. 今までの面接の中で、最も印象的だった質問は何ですか。
4. いま夢中になっているものについて、短くプレゼンしてください。
5. 接客や人と関わる仕事は好きですか。

### 逆質問

1. 現在の業務内容について、具体的にどのような仕事をされていますか。
2. 若手のキャリアパスには、どのようなパターンがありますか。
3. SIerとして働くうえで、特に重要だと感じる視点は何ですか。
4. 今後のIT業界の変化を、大和総研ではどのように捉えていますか。
5. 大和総研のシステム部門では、金融領域以外の案件とどのように関わりますか。
