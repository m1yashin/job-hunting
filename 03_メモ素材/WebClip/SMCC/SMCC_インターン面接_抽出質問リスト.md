# SMCC インターン面接 抽出質問リスト

## 前提

- ワンキャリアの三井住友カード「インターン選考・面接」から質問だけを抽出し、同じ意味の質問を統合した。
- 27卒のマーケティングコース3件、AI・データコース4件を最優先にした。
- 27卒・26卒の「デジタル＆マーケティングコース※現在募集なし」と、25卒・24卒のオープンコースは、再現性を確認する参考情報として扱った。
- 回答案は含めず、面接官に聞かれる形へ整えた。

## 最優先で準備する質問

1. 学生時代に力を入れたことを教えてください。
2. その取り組みを始めた理由は何ですか。
3. その取り組みで最も大変だったことと、乗り越え方を教えてください。
4. チームの人数・活動期間・あなたの役割を教えてください。
5. チーム内の役割分担をどのように決め、周囲とどう連携しましたか。
6. なぜSMCCのインターンシップに応募したのですか。
7. なぜこのコースを選んだのですか。
8. インターンシップで何を学び、どのように貢献したいですか。
9. マーケティングコース：あなたのマーケティング経験と、そこで捉えた顧客インサイトを教えてください。
10. マーケティングコース：実施した施策によって何が改善され、どのような効果がありましたか。
11. AI・データコース：研究の背景・目的・手法を、専門外の人にも分かるように説明してください。
12. AI・データコース：なぜその分析手法を選び、研究上の困難をどう克服しましたか。

## カテゴリ別 質問リスト

### アイスブレイク・自己紹介

- 自己紹介をしてください。
- 趣味について教えてください。
- 部活動やサークルについて教えてください。
- 最近熱中していることは何ですか。
- 面接はこれまで何回ほど経験しましたか。
- 現在、どの業界・企業を見ていますか。

### ガクチカ・挑戦経験

- 学生時代に力を入れたことを教えてください。
- その活動を始めたきっかけは何ですか。
- その活動の目標は何でしたか。
- 活動した時期と期間を教えてください。
- 何人で取り組みましたか。
- あなた自身の役割は何でしたか。
- リーダーはどのように決まりましたか。
- 最も大変だったことは何ですか。
- その困難をどのように乗り越えましたか。
- モチベーションの源泉は何でしたか。
- あなたのどのような強みを生かしましたか。
- 周囲から反対意見が出たとき、どのように対応しましたか。
- その取り組みの反省点は何ですか。
- もう一度取り組むなら、何を変えますか。

### チーム・協働

- チームや組織で協力して取り組んだ経験を教えてください。
- チーム内で普段どのような役割を担いますか。
- チーム内の役割分担をどのように決めましたか。
- 初対面のメンバーとどのようにコミュニケーションを取りましたか。
- メンバーに行動してもらうために、どのような働きかけをしましたか。
- 異なる意見をどのように整理し、合意形成しましたか。
- チームの中で、あなたが貢献したことは何ですか。

### インターン志望理由

- なぜSMCCのインターンシップに応募したのですか。
- なぜ他社ではなくSMCCなのですか。
- なぜこのコースを選んだのですか。
- インターンシップで何を学びたいですか。
- インターンシップで、あなたはどのように活躍・貢献できますか。
- 参加時にはチームでどのような役割を担いたいですか。

### マーケティングコース

- マーケティングに興味を持った理由は何ですか。
- マーケティングの知識・経験について教えてください。
- 長期インターンを始めた理由は何ですか。
- 長期インターンでは、どのような業務を担当しましたか。
- 長期インターンで最も難しかったことは何ですか。
- 施策の対象者をどのように定めましたか。
- 対象者や来場者のどのようなインサイトを捉えましたか。
- そのインサイトを、どのような根拠から導きましたか。
- アプリや施策の導入によって何が改善されましたか。
- そのマーケティング施策には、どのような効果がありましたか。
- 施策の実現可能性をどのように高めましたか。
- 施策の成果をどのような指標で測りましたか。

### AI・データコース

- 大学・大学院では何を研究していますか。
- 研究の背景と目的を教えてください。
- 研究におけるあなたの役割を教えてください。
- 使用している分析手法を、専門外の人にも分かるように説明してください。
- なぜその手法を選んだのですか。
- 研究で最も大変だったことは何ですか。
- 研究上の課題をどのように解決しましたか。
- データ分析や機械学習の経験を教えてください。
- 分析経験の中で、どのようなツール・手法を使いましたか。
- 研究や分析で周囲とどのように協力しましたか。
- なぜキャッシュレスデータに関心があるのですか。
- 研究・分析経験をSMCCのインターンでどう生かせますか。

### 志望業界・価値観

- 現在、どのような業界を見ていますか。
- 就職活動で重視している軸は何ですか。
- なぜマーケティングを軸に就職活動をしているのですか。
- なぜデータ分析を仕事にしたいのですか。
- なぜ金融・決済業界に関心があるのですか。

### 逆質問

- 最後に質問はありますか。

## コース別の優先順位

### 優先順位：マーケティングコース

1. マーケティング経験。
2. 顧客インサイトの捉え方。
3. 施策の改善内容と効果。
4. ガクチカの役割・周囲との関わり。
5. マーケティングへの関心とコース志望理由。

### 優先順位：AI・データコース

1. 研究の背景・目的・手法。
2. 専門用語を使わない研究説明。
3. 手法を選んだ理由と困難の克服。
4. データ分析経験。
5. チームでの役割と参加時の貢献。

## 体験談ごとの質問パターン

### 27卒 マーケティングコース

- 自己紹介・雑談 → ガクチカの事実確認 → 役割分担・対人調整の深掘り。
- ESのマーケティング経験 → 顧客インサイト → 施策による改善 → 効果。
- ガクチカ → 長期インターンの開始理由・困難 → マーケティングへの関心。

### 27卒 AI・データコース

- ガクチカと担当した役割。
- 大学での取り組み → 志望理由 → ガクチカ。
- 自己紹介 → 研究の深掘り → 参加時の貢献 → チームでの役割 → 逆質問。
- 研究の背景・目的・手法・困難 → インターン応募理由 → 逆質問。

### 過年度の共通パターン

- 自己紹介 → ESの一つの経験を深掘り → インターン志望理由。
- ガクチカ → 開始理由 → 困難 → 周囲との関わり → 本人の役割。
- 研究・マーケティング・データ分析経験 → 専門外の面接官にも伝わる説明。
