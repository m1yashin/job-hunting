# 生成AIが開発支援を実現！グローバルで推進するGitHub Copilot

## 基本情報

- 企業: NTTデータ
- 資料名: 生成AIが開発支援を実現！グローバルで推進するGitHub Copilot

- 発行日: 2024-12-23

## 3行要約

- NTTデータは100以上のプロジェクト、2,000以上のユーザーでGitHub Copilotを採用していると説明している。
- 2027年度までにソフトウェア開発工程全体の生産性50%向上を目標としている。
- 生成AI活用を、グローバルでの開発支援・ノウハウ共有・品質向上の取り組みとして位置づけている。

## 経営面的展望

- 開発工程全体の生産性50%向上は、SI事業の収益性・納期・品質に大きく関係する。
- グローバルでノウハウを共有し、開発力を底上げすることが競争力になる。
- 生成AI活用は、個人の効率化ではなく、組織的な開発力強化として扱われている。

## 技術面的展望

- GitHub Copilotを用いたコード生成・補完・開発支援が中心。
- 開発工程全体への適用を見据えており、テストやレビューへの拡張が重要。
- セキュリティや品質を担保する利用ルールとセットで運用する必要がある。

## 経営と技術の接続

- 技術導入が、開発生産性・品質・グローバル標準化という経営課題に接続している。
- AIを使った個人の効率化ではなく、組織のデリバリー力向上が目的。

## 現場業務・開発方法への影響

- 実装作業の一部がAI支援される一方、レビュー・品質判断・仕様理解の重要性が上がる。
- 若手は、AIが生成したコードの意味を理解し、要件や品質基準と照らす必要がある。

## 浮かび上がる人材像

- 生成AIを使って開発速度を上げつつ、品質を落とさない人。
- グローバルな開発標準やナレッジ共有に乗れる人。
- AI出力を検証できる基礎的な実装理解を持つ人。

## 競合比較で使える論点

- NTTデータは、開発支援AIを大規模導入し、生産性目標と結びつけている点が具体的。

## 選考で使えそうな見立て

- AIで実装速度が上がるほど、若手にもレビュー力、仕様理解、品質判断が求められる。
