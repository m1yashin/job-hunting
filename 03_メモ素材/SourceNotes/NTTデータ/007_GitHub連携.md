# GitHubとのビジネス連携によりシステム開発への生成AI適用を推進

## 3行要約

- NTTデータはGitHubとの連携により、生成AIをシステム開発へ適用し、開発プロセスの効率化と品質向上を進める。
- 国内でGitHub Copilotを5,000ユーザーへ広げる目標が示されている。
- 開発生産性16.5%向上など、生成AI活用を現場導入する具体的な動きとして重要。

## 経営面的展望

- 開発生産性と品質を同時に高めることは、SI事業の収益性・競争力に直結する。
- GitHubとの連携は、生成AI活用を社内開発標準・顧客提供へ広げる動き。
- AI-Native開発へ進む前段階として、AI-Assisted開発の大規模展開と見られる。

## 技術面的展望

- GitHub Copilot、Azure OpenAI Serviceなどをシステムインテグレーションや自社サービス開発に活用する。
- コーディング補助だけでなく、設計、テスト、レビュー、エラー解析へ広げる余地がある。
- セキュアな利用環境やガイドライン整備が重要になる。

## 経営と技術の接続

- 経営的には、開発生産性向上によりSI事業の効率・品質・競争力を高める。
- 技術的には、生成AIを開発プロセスに組み込み、標準化・展開する。

## 現場業務・開発方法への影響

- 若手は、Copilotを使って実装するだけでなく、出力をレビューし、品質を担保する力が必要になる。
- 開発チーム内でノウハウ共有、プロンプト、レビュー基準、セキュリティルールが重要になる。

## 浮かび上がる人材像

- 生成AIを安全に活用し、品質向上へつなげられる人。
- チームにAI活用を展開し、ノウハウを標準化できる人。

## 競合比較で使える論点

- NTTデータは、GitHubのようなグローバル開発基盤との連携を、SI現場の生産性向上へ直接つなげている。

## 選考で使えそうな見立て

- AI時代のSEには、ツール利用だけでなく、ツールを組織的に安全・高品質に使う設計力が必要になる。
