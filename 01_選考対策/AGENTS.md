# 01_選考対策/AGENTS.md

## 目的

このフォルダは、就職活動の実戦用フォルダである。
企業ごとの作戦本部と、企業横断で使う共通面接・共通GDを同じ階層で管理する。

## 推奨構成

```text
01_選考対策/
  共通_面接/
    質問/
    回答ユニット/
  共通_GD/
    型/
  企業名/
    企業概要.md
    企業分析.md
    素材要約.md
    面接対策.md
    ES/
      ES一覧.md
      志望動機_300字.md
      ガクチカ_400字.md
    ログ/
      YYYY-MM-DD_企業名_一次面接.md
```

## 配置ルール

- `01_選考対策/企業名/` には、企業固有の情報を置く。
- `01_選考対策/共通_面接/` には、企業横断で使う質問、回答ユニット、自己紹介、ガクチカ、研究説明を置く。
- `01_選考対策/共通_GD/` には、GDの型、発言テンプレ、評価ポイントを置く。
- 企業ごとのESは `01_選考対策/企業名/ES/` に置く。
- 企業ごとの面接、GD、説明会、面談ログは `01_選考対策/企業名/ログ/` に置く。
- Webクリップや素材メモから使える情報の要約は `01_選考対策/企業名/素材要約.md` に置く。
- 原典資料そのものは `03_メモ素材/WebClip/` に置く。

## 企業別面接対策のルール

- `01_選考対策/企業名/面接対策.md` は、原則として質問文だけを並べる。
- 質問文そのものを `###` 見出しにする。
- 回答案、回答要素、深掘り方針は企業別面接対策に直接書き込まず、必要に応じて `共通_面接/回答ユニット/` や別の下書きメモで育てる。
- 企業別対策が複数社たまったら、共通して聞かれる質問や回答ユニットをAIで抽出し、`共通_面接/` に反映する。

## statusの使用ルール

`status` は、企業概要、ES、面接対策のように進捗判断に使うノートだけに付ける。
`企業分析.md` と `素材要約.md` は情報置き場なので、`status` を持たせず `last_reviewed` と本文チェックリストで管理する。

## statusの固定語彙

企業の `status` は以下を使う。

```text
気になる
説明会予定
説明会参加済み
ES作成中
ES提出済み
Webテスト
面接予定
結果待ち
通過
内定
落選
辞退
```

ESの `status` は以下を使う。

```text
未着手
下書き
添削中
完成
提出済み
没
```

面接対策の `status` は以下を使う。

```text
未着手
準備中
直前OK
終了
```

企業ログの `event_type` は以下を使う。

```text
面接
GD
説明会
Webテスト
OB訪問
面談
その他
```

企業ログの `result` は以下を使う。

```text
未定
通過
落選
辞退
保留
内定
```

## 編集方針

- 面接前に企業フォルダを開けば、その企業の状況が分かる状態にする。
- ESは企業情報・素材要約・回答ユニットと接続する。
- `企業概要.md` の `es_index` には、その企業の `ES/ES一覧.md` へのリンクを入れる。
- `企業概要.md` の `interview_prep` には、その企業の `面接対策.md` へのリンクを入れる。
- ログは企業フォルダ内に残し、共通フォルダには置かない。
- 素材要約には原典の丸写しではなく、面接・ESで使える情報だけを書く。
- 企業固有の志望理由は、企業フォルダ内のESや企業別素材に寄せる。
