# 01_選考対策/AGENTS.md

## 文字コード

このファイルとこのフォルダ配下のMarkdownファイルは、文字化けを防ぐためUTF-8で開く。

## 目的

このフォルダには、ES・面接・GDで実際に使う選考対策を置く。

企業ごとの選考対策は `01_選考対策/企業名/` にまとめる。企業概要、事業内容、IR、中期経営計画、競合比較などの事実ベースの企業研究は `02_企業研究/` に置く。このフォルダでは、企業研究から切り出した「自分が選考でどう使うか」を扱う。

## 推奨構成

```text
01_選考対策/
  企業名/
    選考サマリー.md
    志望理由.md
    ES.md
    面接対策.md
    逆質問.md
    GD対策.md
    ログ/
      YYYY-MM-DD_イベント名.md

  共通_面接/
    質問/
    回答ユニット/

  共通_GD/
    型/
```

企業別フォルダは、膨らんでも10ファイル程度に収まるようにする。ESやログが増える場合だけ、必要に応じて `ES/` や `ログ/` のサブフォルダに分ける。

## 置き場所のルール

- `01_選考対策/企業名/` には、その企業の選考で使うES、面接、GD、志望理由、逆質問、ログを置く。
- `選考サマリー.md` は、選考前に見る入口として使う。企業研究の本文は貼らず、必要な選考用メモとリンクだけ置く。
- `志望理由.md` には、自分との接点、志望理由の軸、競合ではなくその会社を選ぶ理由、話す30秒/1分版を置く。
- `ES.md` には、ES設問、下書き、提出用メモ、改善履歴を置く。
- `面接対策.md` には、想定質問、聞かれた質問、深掘り対策、話す材料を置く。
- `逆質問.md` には、説明会、OB訪問、面接で確認する質問を置く。
- `GD対策.md` には、その企業のGDテーマ、評価観点、復習を置く。共通の型は `共通_GD/` に置く。
- 会社概要、事業内容、競合比較、中期経営計画、採用情報、最近のニュースは `02_企業研究/` に置く。
- 原典資料や未整理メモは `03_メモ素材/` に置く。

## 企業別面接対策のルール

企業別の面接対策は `01_選考対策/企業名/面接対策.md` を基本にする。

- `## 質問` の下に、`### 質問文` として並べる。
- 逆質問は `01_選考対策/企業名/逆質問.md` に分けてもよい。
- 質問文は、面接官に聞かれる形に整える。
- 同じ意味の質問は統合する。
- 面接対策には、企業研究本文をそのまま貼らない。
- 企業研究へのリンクは置いてよい。

## 志望理由・逆質問の扱い

志望理由や逆質問は、企業研究ではなく選考対策として扱う。

```text
01_選考対策/企業名/志望理由.md
01_選考対策/企業名/逆質問.md
```

志望理由には、以下を置いてよい。

- 自分との接点
- 志望理由の軸
- 研究経験・AI/DX・PM志向との接続
- 競合ではなくその会社を選ぶ理由
- 面接で話す30秒/1分版

逆質問には、以下を置いてよい。

- 説明会で確認すること
- OB訪問で確認すること
- 面接の逆質問候補
- 配属、働き方、若手裁量、技術成長などの要確認事項

## statusの使用ルール

`status` は進捗判断に使うノートだけに付ける。質問リスト、逆質問候補、GDの型には原則として付けない。

ESの `status` は以下を使う。

```text
未着手
下書き
添削中
完成
提出済み
没
```

面接対策の `status` は以下を使う。

```text
未着手
準備中
直前OK
終了
```

ログの `event_type` は以下を使う。

```text
面接
GD
説明会
Webテスト
OB訪問
面談
その他
```

ログの `result` は以下を使う。

```text
未定
通過
落選
辞退
保留
内定
```

## 編集方針

- 選考前に見返して使える形にする。
- 企業研究の事実を長く貼らず、必要な場合は `02_企業研究/` の該当ノートへリンクする。
- 企業研究から得た事実を使う場合は、出典が残っていることを確認する。
- 志望理由や逆質問では、事実、解釈、仮説を混ぜすぎない。
- 配属、社風、若手裁量、残業、昇進などは「仮説」または「要確認」として扱う。
- 面接後やGD後のログは、聞かれたこと、詰まったこと、次回直すことに落とす。
