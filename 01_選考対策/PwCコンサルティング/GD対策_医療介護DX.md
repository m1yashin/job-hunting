# PwC GD対策シート 医療介護DX

## まず結論

医療介護DXは、「オンライン診療を増やす」「介護ロボットを入れる」という単発施策ではなく、医療・介護・自治体・患者本人の情報をつなぎ、人手不足の中でも質と安全を保つ仕組みに変える話。

GDでの勝ち筋は、次の順番で考えること。

```text
対象者を決める
医療か介護か、または連携部分かを決める
業務工程を分解する
一番詰まっている工程を選ぶ
データ連携・業務効率化・遠隔化・予防のどれで解くか決める
安全性・個人情報・現場定着まで話す
```

いきなり「AI診断」「オンライン診療」「介護ロボット」と言わない。  
先に「誰のどの負担を、どのデータで、どのKPIで改善するか」を決める。

## GDで出そうなお題

- 医療介護問題について。
- 医療・介護分野における人手不足をDXで解決するには。
- 高齢化社会において、医療・介護の質を保つためのデジタル施策を提案する。
- 地域包括ケアを実現するために、どのようなIT施策が必要か。
- 介護施設の職員負担を軽減する施策を考える。
- 病院の待ち時間を減らすためのデジタル施策を考える。
- 高齢者が住み慣れた地域で生活し続けるためのDX施策を考える。
- 医療機関と介護施設の情報連携を改善する方法を考える。
- オンライン診療を普及させるための課題と施策を考える。
- 介護ロボットや見守りセンサーを現場に定着させる方法を考える。

## 最初に置くべき前提

医療介護DXは範囲が広すぎる。最初に対象を絞る。

```text
医療介護DXは広いので、今回は高齢者の在宅・施設介護と、医療機関との連携部分に絞りませんか。
ゴールは、短期的には職員の業務時間削減、中期的には転倒・重複投薬などのリスク低減、長期的には住み慣れた地域で生活できる人を増やすことに置きたいです。
```

クライアントを置くなら、PwCらしく「自治体」「地域の医療法人」「介護事業者グループ」「保険者」にする。

```text
クライアントを地方自治体と仮定し、地域包括ケアを支える医療・介護データ連携と、介護現場の生産性向上を考えたいです。
```

## 基礎ファクト

暗記する数字は少なくてよい。GDでは以下だけで十分。

- 内閣府「令和7年版高齢社会白書」によると、令和6年10月1日時点の日本の高齢化率は29.3%。65歳以上人口は3,624万人。
- 75歳以上人口は2,078万人で、総人口の16.8%。65〜74歳人口を上回っている。
- 厚生労働省によると、介護職員は2022年度の215万人に対し、2026年度には約240万人、2040年度には約272万人が必要と推計されている。
- つまり、2040年度には2022年度比で約57万人の介護職員を追加確保する必要がある。
- 厚労省の医療DX施策には、電子カルテ情報共有サービス、標準型電子カルテ、電子処方箋、医療費助成のオンライン資格確認、予防接種事務のデジタル化、介護情報基盤などがある。
- 電子処方箋は、処方箋の電子化だけでなく、複数の医療機関・薬局で直近に処方・調剤された情報を参照し、重複投薬等チェックを行える仕組み。
- 介護情報基盤は、介護サービス利用者の情報を、本人同意の下で利用者、自治体、介護事業所、医療機関等の関係者間で共有する取組。
- 地域包括支援センターは、地域包括ケア実現に向けた中核的機関として市町村が設置している。令和7年4月末時点で全国5,487か所、ブランチを含めると7,374か所。

出典は末尾にまとめる。

## 医療介護DXの本質

### 医療DXと介護DXの違い

```text
医療DX:
医療機関、薬局、自治体、患者本人の情報を連携し、診療・処方・検査・予防接種・請求などを安全かつ効率的にすること。

介護DX:
介護現場の記録、見守り、シフト、ケアプラン、医療連携などをデジタル化し、少ない人手でもケアの質を保つこと。

医療介護DX:
医療と介護を分けず、患者・利用者を中心に情報と業務をつなぎ、地域で支える仕組みに変えること。
```

GDでは、医療DXだけだと「病院の効率化」、介護DXだけだと「施設の省人化」で止まりやすい。  
PwCらしくするなら、「地域の医療・介護・自治体をつなぐ変革」まで持っていく。

## 課題構造

### 1. 高齢化で需要が増える

医療・介護は、高齢化により需要が増える。  
特に75歳以上が増えると、慢性疾患、複数疾患、服薬管理、介護、認知症、在宅療養などのニーズが増える。

施策の方向性:

- 予防・早期発見。
- 在宅医療・オンライン診療。
- 医療と介護の情報共有。
- 重症化予防。
- 高齢者本人・家族へのセルフケア支援。

### 2. 介護人材が足りない

介護では、身体介助、記録、夜間巡視、移動、申し送り、シフト調整など、多くの業務が人に依存している。  
人手不足の本質は、「人が少ない」だけでなく、「専門職が本来やるべきケア以外の業務にも時間を取られている」こと。

施策の方向性:

- 記録業務の自動化・音声入力。
- 見守りセンサー。
- インカム・タブレット。
- シフト最適化。
- 介護助手との役割分担。
- ケアの標準化。

### 3. 医療と介護の情報が分断されている

病院、診療所、薬局、介護施設、ケアマネジャー、自治体がそれぞれ情報を持っている。  
退院時、在宅療養、施設入所、急変時に情報がつながらないと、確認作業や判断ミスが増える。

施策の方向性:

- 電子カルテ情報共有。
- 電子処方箋。
- 介護情報基盤。
- 退院サマリー・ケアプラン共有。
- 地域包括ケアの情報連携。

### 4. 現場の事務負担が重い

医療・介護は、記録、請求、行政提出、同意取得、家族連絡など、バックオフィス業務が多い。  
DXの価値は、患者対応やケアに使う時間を増やすことにある。

施策の方向性:

- 電子カルテ・介護記録の標準化。
- 音声入力。
- RPA・生成AIによる文書作成支援。
- オンライン資格確認。
- 電子請求。
- 自治体手続きのデジタル化。

### 5. 安全性と個人情報の制約が大きい

医療介護データはセンシティブであり、単にデータ共有すればよいわけではない。  
本人同意、アクセス権限、誤情報、サイバーセキュリティ、責任分界が重要。

施策の方向性:

- 本人同意管理。
- アクセスログ。
- 権限設計。
- データ標準化。
- 監査。
- 人が最終判断する運用。

## 業務工程で分解する

医療介護DXのお題が来たら、業務工程に分ける。

```text

介護側

見守り
介護記録

```

GDでは全工程を解こうとしない。  
一番詰まっている工程を選ぶ。

```text
今回は介護人材不足がテーマなので、職員の時間を大きく奪っている夜間見守り、介護記録、申し送りに絞るのがよいと思います。
```

```text
医療介護連携がテーマなら、退院時から在宅・施設へ移る部分に絞ると、情報共有の価値が出やすいです。
```

## 施策が生まれる思考パターン

### パターン1: 同じ情報を何度も聞く・書く

課題:

- 問診票、カルテ、紹介状、介護記録、ケアプランに同じ情報が重複する。
- 患者・家族も同じ説明を何度もする。
- 現場は転記に時間を取られる。

思考:

```text
同じ情報を複数の場所で使うなら、標準化して一度入力・複数利用にする。
```

施策:

- 電子カルテ情報共有。
- 標準型電子カルテ。
- 介護情報基盤。
- 問診のデジタル化。
- 退院サマリー・ケアプランの共有。
- RPAによる転記削減。

言い方:

```text
この課題は、医療や介護の質以前に、情報が分断されて同じ入力・確認が繰り返されていることが原因です。まずは共通で使う情報を標準化し、一度入力した情報を医療機関、薬局、介護事業所で使えるようにするべきです。
```

### パターン2: 人が見回って確認している

課題:

- 介護施設の夜間巡視。
- 転倒リスクの確認。
- ベッド上の状態確認。
- 排泄タイミングの確認。
- 在宅高齢者の安否確認。

思考:

```text
人が現地に行って確認しているだけなら、センサーと通知で置き換える。
```

施策:

- 見守りセンサー。
- ベッドセンサー。
- 転倒検知。
- 排泄予測。
- 在宅見守りIoT。
- 異常時アラート。

言い方:

```text
夜間巡視は重要ですが、全員を同じ頻度で見に行くと職員負担が大きいです。センサーでリスクの高い人を可視化し、必要なタイミングで介入する形に変えるべきです。
```

### パターン3: 専門職が事務作業に追われている

課題:

- 医師、看護師、介護職が記録や書類作成に時間を取られる。
- 本来の診療・ケアに使う時間が削られる。
- 記録漏れや申し送りミスが起きる。

思考:

```text
専門職がやるべき判断・ケアと、システムで代替できる記録・整理を分ける。
```

施策:

- 音声入力。
- AI記録要約。
- 介護記録アプリ。
- 申し送り自動生成。
- シフト・勤怠管理。
- 請求業務の自動化。

言い方:

```text
人手不足の中では、専門職の時間を増やすより、専門職が本来やるべきケア以外の業務を減らすことが重要です。
```

### パターン4: 医療と介護の切れ目でリスクが出る

課題:

- 退院後の生活状況が医療側に見えない。
- 介護施設が既往歴や薬剤情報を十分に把握できない。
- 急変時に必要情報がすぐ出ない。
- 薬の重複や飲み合わせリスクがある。

思考:

```text
リスクは組織の境界で起きる。境界部分の情報連携をDXする。
```

施策:

- 電子処方箋。
- 薬剤情報共有。
- 退院サマリー共有。
- ケアプラン共有。
- 急変時情報セット。
- 医療介護連携ダッシュボード。

言い方:

```text
医療介護DXで一番効果が出るのは、病院内の効率化だけでなく、退院後や施設入所時の情報連携です。ここで情報が切れると、重複投薬や急変時対応の遅れにつながります。
```

### パターン5: 地域差が大きい

課題:

- 都市部は需要が集中する。
- 地方は医師・介護人材・交通手段が不足する。
- 高齢者のデジタル利用に差がある。
- 医療資源の偏在がある。

思考:

```text
全国一律のアプリではなく、地域の医療資源と住民特性に合わせた運用にする。
```

施策:

- オンライン診療。
- 遠隔服薬指導。
- 移動診療・訪問看護との連携。
- 地域包括支援センターの相談データ活用。
- 自治体主導の高齢者デジタル支援。

言い方:

```text
医療介護DXは全国一律のアプリ導入ではなく、地域の医療資源の不足を補う設計にする必要があります。都市部と地方で課題が違うため、自治体単位で優先施策を変えるべきです。
```

## 主要施策カード

### 施策1: 医療・介護情報連携基盤

向いている課題:

- 医療と介護の情報分断。
- 退院後のケアへの情報引き継ぎ。
- 急変時対応。
- 多職種連携。
- 介護施設での医療情報不足。

施策内容:

- 電子カルテ情報、薬剤情報、検査結果、退院サマリー、ケアプランを連携する。
- 本人同意の下で、医療機関、薬局、介護事業所、自治体が必要情報を閲覧できるようにする。
- 急変時に必要な情報だけをすぐ見られる画面を作る。

なぜ生まれるか:

医療介護の問題は、各現場が頑張っていても、情報が組織ごとに切れていることにある。  
特に高齢者は複数疾患・複数薬剤・複数サービスを使うため、連携価値が大きい。

効果:

- 情報確認時間の削減。
- 重複検査・重複説明の削減。
- 急変時対応の迅速化。
- 医療・介護サービスの質向上。
- 家族の説明負担軽減。

KPI:

- 退院サマリー共有率。
- 情報照会時間。
- 重複検査件数。
- 急変時の情報確認時間。
- 多職種会議の準備時間。
- 利用者・家族満足度。

注意点:

- 個人情報保護。
- 本人同意。
- アクセス権限。
- 既存システムとの連携。
- 現場が入力し続けられる運用。

GDでの使い方:

```text
医療介護DXの中核は、単なるオンライン化ではなく、病院、薬局、介護施設、自治体の情報連携だと思います。特に退院時や急変時のような組織の境界でリスクが出るため、必要情報を本人同意の下で共有できる基盤が重要です。
```

### 施策2: 電子処方箋・薬剤情報共有

向いている課題:

- 重複投薬。
- 併用禁忌。
- お薬手帳忘れ。
- 複数医療機関の受診。
- 高齢者の多剤服用。

施策内容:

- 処方箋を電子化する。
- 複数の医療機関・薬局で直近の処方・調剤情報を参照できるようにする。
- 重複投薬等チェックを行う。
- 医師・薬剤師が処方前後に確認する。

なぜ生まれるか:

高齢者は複数の病院にかかり、複数の薬を飲むことが多い。  
薬剤情報が患者の記憶や紙のお薬手帳に依存すると、重複や飲み合わせリスクが残る。

効果:

- 重複投薬防止。
- 併用禁忌リスク低減。
- 薬局での疑義照会効率化。
- 患者安全の向上。
- 薬剤費適正化。

KPI:

- 電子処方箋利用率。
- 重複投薬アラート件数。
- 処方変更件数。
- 疑義照会件数・時間。
- 薬剤関連インシデント。

注意点:

- 医療機関・薬局の導入率。
- 患者同意。
- アラート過多。
- 現場フローに合わないと使われない。

GDでの使い方:

```text
高齢者医療では、薬剤情報の分断が安全性に直結します。電子処方箋は単なる紙の電子化ではなく、複数医療機関・薬局をまたいで重複投薬を確認できる点に価値があります。
```

### 施策3: 見守りセンサーと夜間業務改革

向いている課題:

- 介護施設の夜間巡視。
- 転倒リスク。
- 職員の心理的負担。
- 夜勤人材不足。
- 入居者の睡眠を妨げる巡視。

施策内容:

- ベッドセンサー、離床センサー、カメラではないプライバシー配慮型センサーを導入する。
- 職員のスマホ・インカムへ通知する。
- 介護記録と連携する。
- 全員一律巡視から、リスクに応じた巡視へ変える。

なぜ生まれるか:

夜間巡視は安全のために必要だが、全員を同じ頻度で見回ると職員負担が大きい。  
センサーでリスクを可視化すれば、必要な人に必要なタイミングで対応できる。

効果:

- 巡視時間削減。
- 転倒予防。
- 職員の負担軽減。
- 利用者の睡眠の質向上。
- 夜勤配置の安定。

KPI:

- 夜間巡視回数。
- 夜勤職員の移動時間。
- 転倒件数。
- アラート対応時間。
- 職員満足度。
- 離職率。

注意点:

- 誤検知・通知疲れ。
- プライバシー。
- センサーだけ入れて業務フローを変えないと効果が出ない。
- 介護記録との連携。

GDでの使い方:

```text
介護施設では、見守りセンサーを単体導入するのではなく、夜間巡視の業務フローそのものを変える必要があります。一律巡視からリスクに応じた巡視へ変えることで、職員負担と転倒リスクの両方を下げられます。
```

### 施策4: 介護記録・申し送りのデジタル化

向いている課題:

- 紙記録。
- 転記。
- 申し送り漏れ。
- 記録作業の残業。
- 多職種連携。

施策内容:

- タブレットやスマホで介護記録を入力する。
- 音声入力・定型文を使う。

## ありがちな失敗

### 失敗2: オンライン診療ですべて解く

悪い例:

```text
高齢者はオンライン診療にすれば通院しなくて済みます。
```

```text
オンライン診療は、慢性疾患の定期フォローや在宅療養支援には有効ですが、急性症状や初期判断には対面が必要な場合もあります。対面との切替基準を設けるべきです。
```

### 失敗3: 介護ロボットだけで人手不足を解く

悪い例:

```text
介護ロボットを入れれば人手不足は解消します。
```

```text
介護ロボットは一部業務の負担軽減には有効ですが、記録、申し送り、シフト、役割分担まで変えないと人手不足の根本解決にはなりません。
```

### 失敗4: 現場の入力負担を増やす

悪い例:

```text
すべての介護データを細かく入力してもらいます。
```

改善:

```text
現場の入力負担が増えると定着しません。音声入力、定型文、センサー連携で、記録を楽にする設計が必要です。
```

### 失敗5: 個人情報を軽く扱う

悪い例:

```text
病院と介護施設で全部の情報を共有します。
```

改善:

```text
共有する情報は目的に応じて絞り、本人同意、アクセス権限、ログ管理を設計する必要があります。急変時に必要な情報と日常ケアに必要な情報を分けるべきです。
```

```text
AI診断のような高度な施策より、まず情報連携と記録業務の削減を優先する方が実現性が高いと思います。
```

### PwCっぽくまとめる時

```text
単なるシステム導入ではなく、業務プロセス、データ連携、現場教育、制度対応まで含めて設計する必要があります。
```

```text
自治体、医療機関、薬局、介護事業者がそれぞれ別にDXするのではなく、利用者を中心に地域単位でつなぐことが重要です。
```

## 最強の提案パッケージ

迷ったらこの提案に寄せる。

### 地域医療介護連携プラットフォーム

対象:

- 地方自治体。
- 地域の医療法人。
- 薬局。
- 介護施設。
- ケアマネジャー。
- 地域包括支援センター。

課題:

- 介護人材不足。
- 医療と介護の情報分断。
- 退院後の引き継ぎ不足。
- 重複投薬や急変時対応のリスク。
- 家族・本人の説明負担。
- 現場の記録・申し送り負担。

施策:

1. 電子カルテ情報、薬剤情報、退院サマリー、ケアプランのうち、必要情報を本人同意の下で共有する。
2. 介護施設では見守りセンサーと介護記録システムを導入し、夜間巡視と記録業務を削減する。
3. 電子処方箋を活用し、重複投薬等チェックを行う。
4. 地域包括支援センターの相談データを可視化し、介護予防や早期支援につなげる。
5. 導入時は、医療機関・介護事業者・自治体向けに業務フロー変更と研修をセットで行う。

なぜ強いか:

- 医療と介護の両方に効く。
- 人手不足と安全性の両方を解ける。
- 厚労省の医療DX・介護情報基盤の流れと合う。
- PwCらしく、技術導入だけでなく業務変革と組織間連携になっている。
- 自治体や地域医療法人をクライアントに置きやすい。

KPI:

- 介護記録時間。
- 夜間巡視回数。
- 退院サマリー共有率。
- 急変時の情報確認時間。
- 重複投薬アラート件数。
- 介護職員の残業時間。
- 職員満足度。
- 転倒件数。
- 再入院率。
- 利用者・家族満足度。

発表例:

```text
私たちは、地域医療介護連携プラットフォームを提案します。
高齢化により医療・介護需要が増える一方、介護人材は2040年度に約272万人必要と推計されており、人手不足が深刻です。
そのため、自治体が中心となって、病院、薬局、介護施設、地域包括支援センターをつなぎ、薬剤情報、退院サマリー、ケアプラン、介護記録の一部を本人同意の下で共有します。
同時に、介護施設には見守りセンサーと記録DXを導入し、夜間巡視や申し送りの負担を減らします。
これにより、現場の業務時間を削減しながら、重複投薬や急変時対応のリスクも下げられます。
```

## 30秒回答テンプレート

### 医療介護問題をDXで解決するなら

```text
私は、地域医療介護連携プラットフォームを提案します。
医療介護の課題は、人手不足だけでなく、病院、薬局、介護施設、自治体の情報が分断されている点にあります。
そのため、本人同意の下で、薬剤情報、退院サマリー、ケアプラン、介護記録の一部を共有し、退院後や急変時の対応を円滑にします。
同時に、介護施設では見守りセンサーと記録DXを導入し、職員の夜間巡視や申し送りの負担を減らします。
```

### 介護人材不足を聞かれたら

```text
介護人材不足は、採用だけで解くのではなく、業務を分解して職員の負担を減らす必要があります。
具体的には、見守りセンサーで夜間巡視をリスク対応型に変え、介護記録をタブレットや音声入力で効率化します。
さらに、シフト最適化や介護助手の活用により、有資格者が専門性の高いケアに集中できる体制を作るべきです。
```

### オンライン診療を聞かれたら

```text
オンライン診療は、全ての診療を置き換えるのではなく、慢性疾患の定期フォローや在宅療養支援に絞るのが現実的です。
高齢者本人だけに操作を任せるのではなく、薬局や訪問看護、地域拠点が接続を支援し、必要時には対面診療へ切り替える基準を明確にすることで、安全性と利便性を両立できます。
```
