# PwC GD対策シート フードロス・環境・公共交通

## まず結論

フードロス・環境・公共交通は、どれも「社会的に良いことを啓発する」だけでは弱い。  
GDで強い答えは、企業・自治体・消費者の行動が変わるように、データ、インセンティブ、運用設計を組み合わせること。

```text
フードロス:
需要予測、値引き、在庫管理、寄付、消費者行動変容

環境:
利便性・コスト・環境価値のバランス設計

公共交通:
交通空白、利用促進、予約型交通、MaaS、公共ライドシェア
```

いきなり「環境意識を高める」「公共交通を使うよう呼びかける」と言わない。  
行動が変わらない理由を分解し、摩擦を下げる・得になる・分かりやすくする施策に落とす。

## GDで出そうなお題

- フードロスについて。
- ITと環境にまつわるもの。
- 公共交通機関の利用促進を図る施策。
- 地方観光に関する課題への施策。
- 環境配慮と利便性を両立するサービスを考える。
- 小売店や飲食店の食品ロスを減らす施策を考える。
- 自治体が食品ロスを減らすためにできることを考える。
- 地域公共交通の利用者を増やす施策を考える。
- 交通空白地帯を解消する施策を考える。
- 環境負荷を下げながら、事業者の収益性を保つ方法を考える。

## 最初に置くべき前提

テーマが広いので、対象を絞る。

```text
フードロスと環境は広いので、今回は小売・外食で発生する食品ロス削減に絞りませんか。
ゴールは、廃棄量削減だけでなく、利益率改善と消費者満足の両立に置きたいです。
```

公共交通なら、

```text
公共交通は都市部と地方で課題が違うので、今回は地方の交通空白と、都市部の自家用車から公共交通への転換を分けて考えたいです。
```

クライアントを置くなら、食品ロスは「食品スーパー・外食チェーン・自治体」、公共交通は「地方自治体・鉄道/バス会社・観光地」がよい。

## 基礎ファクト

暗記する事実は以下で十分。

- 農林水産省・環境省によると、令和5年度の日本の食品ロス量は約464万トン。事業系が約231万トン、家庭系が約233万トン。
- 農林水産省は、食品ロスを「本来食べられるのに捨てられてしまう食品」と説明している。
- 家庭系食品ロスは、食べ残し、直接廃棄、過剰除去に分類される。
- 事業系食品ロスは、食品製造業、食品卸売業、食品小売業、外食産業から発生する。
- 食品ロス削減推進法は、国、地方公共団体、事業者、消費者などの責務を明らかにし、食品ロス削減を総合的に推進する法律。
- 国土交通省は、地域公共交通のリ・デザインや交通空白解消を進めている。
- 地域公共交通では、公共ライドシェア、デマンド交通、共同化・協業化、MaaS、観光二次交通などが論点になる。

出典は末尾にまとめる。

## このテーマの本質

### フードロスと環境の関係

```text
フードロス:
食べられる食品が廃棄されること。

環境負荷:
食品の生産、加工、輸送、販売、廃棄にかかる資源・エネルギー・CO2・廃棄処理負荷。

食品ロス削減:
食品の廃棄を減らすことで、企業の廃棄コスト、消費者の支出、環境負荷を同時に下げること。
```

食品ロスは「もったいない」だけでなく、事業者の利益改善テーマでもある。  
PwCらしくするなら、廃棄削減、需要予測、在庫回転、値引き、寄付、消費者行動変容をつなぐ。

### 公共交通と環境の関係

```text
公共交通利用促進:
自家用車に依存しすぎず、鉄道・バス・乗合交通・自転車・徒歩を組み合わせること。

交通空白解消:
公共交通が弱い地域で、高齢者や観光客が移動できない状態を解消すること。

環境価値:
自家用車利用を減らし、渋滞・CO2・駐車場負荷を下げること。
```

公共交通は、環境だけでなく、地域生活、観光、医療アクセス、高齢者の外出、自治体財政とつながる。

## 課題構造

### 1. 需要予測が弱い

食品ロスは、需要より多く作る・仕入れる・並べることで発生する。  
天気、曜日、イベント、過去販売、地域特性を使えば、需要予測で減らせる。

施策の方向性:

- AI需要予測。
- 発注自動化。
- 在庫可視化。
- 賞味期限管理。
- 売れ残り予測。

### 2. 消費者が完璧な品揃えを期待する

閉店間際でも棚が満たされていること、賞味期限が長いこと、見た目がきれいなことを求めると、ロスが増える。  
消費者の行動変容が必要。

施策の方向性:

- てまえどり。
- 規格外品販売。
- 期限近商品へのポイント。
- 売り切れ許容のコミュニケーション。
- 食べきりサイズ。

### 3. 値引きタイミングが難しい

早く値引きしすぎると利益が下がる。  
遅すぎると廃棄になる。  
需要と在庫に応じた動的値引きが効く。

施策の方向性:

- ダイナミックプライシング。
- 値引き通知。
- 廃棄予測。
- アプリでの取り置き。
- 店舗ごとの値引き最適化。

### 4. 寄付・再流通の仕組みが弱い

売れ残りをフードバンクや子ども食堂に回すには、品質管理、配送、責任分界、マッチングが必要。  
善意だけでは続かない。

施策の方向性:

- フードバンク連携。
- 寄付マッチング。
- 温度管理。
- 回収ルート設計。
- 税務・責任ルール整理。

### 5. 公共交通は利便性で負ける

公共交通を使ってほしいと言っても、便数が少ない、乗継が悪い、運賃が分かりにくい、終電が早いと使われない。  
環境意識だけでは行動は変わらない。

施策の方向性:

- MaaSアプリ。
- 経路検索・予約・決済統合。
- デマンド交通。
- 観光周遊パス。
- 駅・バス・シェアサイクル連携。
- 混雑情報。

### 6. 地方では交通空白がある

地方ではバス路線の縮小、タクシー不足、高齢者の免許返納、観光地の二次交通不足が重なる。  
公共交通利用促進というより、最低限の移動手段確保が課題。

施策の方向性:

- 予約型乗合交通。
- 公共ライドシェア。
- 自治体・NPO連携。
- 通院・買い物便。
- 観光ピーク時の臨時交通。

## 工程で分解する

フードロスなら、工程はこう分ける。

```text
需要予測
曜日、天気、イベント、過去販売、予約

仕入れ・製造
発注量、製造量、規格外品、賞味期限

販売
陳列、値引き、販促、てまえどり、予約

余剰発生
売れ残り、期限間近、キャンセル、食べ残し

再利用
寄付、再販売、飼料化、肥料化

廃棄
廃棄コスト、CO2、自治体処理
```

公共交通なら、工程はこう分ける。

```text
移動ニーズ
通勤、通学、通院、買い物、観光

情報取得
経路、時刻、運賃、混雑、乗継

予約・決済
チケット、定期、乗合交通、観光パス

移動
鉄道、バス、タクシー、ライドシェア、自転車、徒歩

乗継
駅、バス停、ラストワンマイル

継続利用
ポイント、定額、利便性、安心感
```

## 施策が生まれる思考パターン

### パターン1: 余る量が読めない

課題:

- 売れ残り。
- 発注過多。
- 天気やイベントで需要が変動。
- 店長の勘に依存。

思考:

```text
需要が読めないなら、過去販売・天気・イベントで予測し、発注と値引きに反映する。
```

施策:

- AI需要予測。
- 自動発注。
- 廃棄予測。
- 値引き最適化。
- 店舗別ダッシュボード。

言い方:

```text
食品ロスは啓発だけでなく、需要予測と発注精度の問題です。天気やイベント、過去販売データを使って発注量と値引きタイミングを最適化すべきです。
```

### パターン2: 消費者が期限の長い商品を選ぶ

課題:

- 奥から商品を取る。
- 期限近商品が残る。
- 売れ残りが増える。

思考:

```text
消費者行動が原因なら、環境意識だけでなく得になる仕組みを作る。
```

施策:

- てまえどりポイント。
- 期限近商品のアプリ通知。
- 値引きクーポン。
- 購入後すぐ食べる人向け訴求。

言い方:

```text
消費者に我慢を求めるより、期限近商品を選ぶとポイントが付くなど、得になる設計にした方が行動が変わりやすいです。
```

### パターン3: まだ食べられるが売れない

課題:

- 規格外品。
- 期限間近。
- 外食のキャンセル。
- 食べ残し。

思考:

```text
廃棄前に、値引き、再販売、寄付、別用途化の順に流す。
```

施策:

- フードシェアリングアプリ。
- フードバンク連携。
- 規格外品EC。
- 食べきりメニュー。
- 持ち帰り容器。

言い方:

```text
食品ロスは、廃棄の直前で考えるのではなく、値引き販売、寄付、再利用のルートを事前に設計しておく必要があります。
```

### パターン4: 公共交通が不便

課題:

- 経路が分かりにくい。
- 乗継が悪い。
- 運賃が分かりにくい。
- 便数が少ない。

思考:

```text
使われない理由が不便さなら、情報・予約・決済・乗継を一つにまとめる。
```

施策:

- MaaSアプリ。
- 経路検索。
- 一括決済。
- 観光周遊パス。
- バスロケーション。
- 混雑情報。

言い方:

```text
公共交通利用促進では、環境啓発より、経路検索、予約、決済、乗継を簡単にすることが重要です。自家用車より面倒であれば使われません。
```

### パターン5: 地方で交通手段がない

課題:

- バス路線縮小。
- タクシー不足。
- 高齢者の通院・買い物。
- 観光地の二次交通不足。

思考:

```text
固定路線が成り立たないなら、予約型・乗合型・地域互助型にする。
```

施策:

- デマンド交通。
- 公共ライドシェア。
- NPO・住民ドライバー。
- 通院・買い物便。
- 観光シャトル。

言い方:

```text
地方では公共交通利用促進というより、交通空白の解消が先です。定時定路線にこだわらず、予約型乗合交通や公共ライドシェアを組み合わせるべきです。
```

## 主要施策カード

### 施策1: AI需要予測・自動発注

向いている課題:

- 小売の売れ残り。
- 外食の仕込み過多。
- 天気や曜日による需要変動。
- 店長の経験依存。

施策内容:

- POSデータ、天気、曜日、イベント、地域データを使って需要を予測する。
- 発注量や製造量を提案する。
- 廃棄予測を出す。
- 店舗ごとのロス率を可視化する。

なぜ生まれるか:

食品ロスの多くは、需要より多く作る・仕入れることで起きる。  
需要予測はロス削減と利益改善を同時に狙える。

効果:

- 廃棄量削減。
- 欠品削減。
- 粗利改善。
- 店舗作業の標準化。

KPI:

- 食品廃棄量。
- 廃棄率。
- 欠品率。
- 粗利率。
- 発注作業時間。

注意点:

- 需要予測が外れると欠品が起きる。
- 店舗現場の判断余地。
- データ品質。
- 季節・イベント変動。

GDでの使い方:

```text
小売・外食の食品ロス削減では、まず需要予測と発注精度の改善が有効です。POS、天気、曜日、イベント情報を使って、作りすぎ・仕入れすぎを減らします。
```

### 施策2: 期限近商品のダイナミック値引き

向いている課題:

- 売れ残り。
- 期限近商品の廃棄。
- 値引きタイミングの属人化。

施策内容:

- 賞味期限、在庫、販売速度から値引きタイミングを自動提案する。
- アプリで期限近商品を通知する。
- すぐ食べる人向けにポイントやクーポンを出す。

なぜ生まれるか:

値引きは早すぎると利益が下がり、遅すぎると廃棄になる。  
データで最適なタイミングを探ることで、廃棄と粗利のバランスを取れる。

効果:

- 廃棄削減。
- 粗利維持。
- 顧客来店促進。
- 食品ロス意識向上。

KPI:

- 期限近商品販売率。
- 廃棄率。
- 値引き後粗利。
- アプリ通知開封率。
- てまえどり率。

注意点:

- 値引き待ちを誘発する可能性。
- ブランド毀損。
- オペレーション負担。
- アプリ利用者以外への対応。

GDでの使い方:

```text
食品ロス削減では、期限近商品を一律値引きするのではなく、販売速度に応じて値引きタイミングを最適化することが重要です。
```

### 施策3: フードシェアリング・寄付マッチング

向いている課題:

- まだ食べられる売れ残り。
- 外食のキャンセル。
- 規格外品。
- フードバンクとの接続不足。

施策内容:

- 店舗の余剰食品をアプリで販売・寄付する。
- フードバンク、子ども食堂、地域団体とマッチングする。
- 回収ルート、温度管理、受取時間を管理する。
- 責任分界を明確にする。

なぜ生まれるか:

余剰食品は、廃棄前に売る・寄付するルートがないと捨てられる。  
マッチングと物流を組み合わせることで、廃棄を減らせる。

効果:

- 廃棄削減。
- 地域支援。
- 店舗の廃棄コスト削減。
- ブランド価値向上。

KPI:

- マッチング量。
- 廃棄削減量。
- 寄付件数。
- 回収成功率。
- 廃棄コスト。

注意点:

- 食品安全。
- 温度管理。
- 責任分界。
- 回収コスト。
- 継続運用。

GDでの使い方:

```text
売れ残りを廃棄する前に、値引き販売、フードシェアリング、寄付へ流す仕組みを作るべきです。ただし食品安全と責任分界を設計する必要があります。
```

### 施策4: 家庭向け食品ロス削減アプリ

向いている課題:

- 家庭系食品ロス。
- 冷蔵庫内の期限切れ。
- 買いすぎ。
- 食べ残し。

施策内容:

- 購入食品を登録する。
- 賞味期限を通知する。
- 余り食材からレシピを提案する。
- 買い物リストを作る。
- 食品ロス削減量を可視化する。

なぜ生まれるか:

家庭系ロスは、直接廃棄、食べ残し、過剰除去が中心。  
買う、保存する、使い切る、の工程を支援すれば減らせる。

効果:

- 期限切れ削減。
- 食費削減。
- 環境意識向上。
- 家庭内在庫の見える化。

KPI:

- 登録食材数。
- 期限切れ通知後使用率。
- 食品ロス削減量。
- 月間利用率。
- 食費削減額。

注意点:

- 入力が面倒。
- 継続率。
- 高齢者対応。
- 実際の廃棄量測定が難しい。

GDでの使い方:

```text
家庭系食品ロスには、冷蔵庫内の可視化と期限通知が有効です。ただし入力負担が大きいと続かないため、レシート連携や簡単登録が重要です。
```

### 施策5: MaaS・公共交通利用促進アプリ

向いている課題:

- 公共交通の利用ハードル。
- 乗継の分かりにくさ。
- 運賃・時刻表の分断。
- 観光地の二次交通。

施策内容:

- 鉄道、バス、タクシー、シェアサイクル、徒歩を一括検索する。
- 予約・決済を統合する。
- 混雑情報や遅延情報を出す。
- 観光周遊パスや地域定額券を提供する。

なぜ生まれるか:

公共交通は、個別サービスは存在しても、利用者から見ると情報・予約・決済が分断されている。  
乗り換えを簡単にすれば、車から公共交通への転換が起こりやすい。

効果:

- 公共交通利用増。
- 観光回遊増。
- 自家用車依存低下。
- 混雑分散。

KPI:

- アプリ利用者数。
- 公共交通利用回数。
- 周遊パス販売数。
- 乗継成功率。
- 観光地回遊数。

注意点:

- 交通事業者間の連携。
- 運賃収入配分。
- データ標準化。
- 高齢者向け代替手段。

GDでの使い方:

```text
公共交通利用促進では、経路検索、予約、決済、観光パスを統合するMaaSが有効です。利用者から見て自家用車より面倒でない状態にする必要があります。
```

### 施策6: 予約型乗合交通・公共ライドシェア

向いている課題:

- 地方の交通空白。
- 高齢者の通院・買い物。
- バス路線縮小。
- タクシー不足。

施策内容:

- 利用者が事前予約する。
- AI配車で乗合ルートを組む。
- 住民ドライバーやNPO、自治体が連携する。
- 電話予約も残す。
- 通院・買い物・駅接続を重点化する。

なぜ生まれるか:

人口密度が低い地域では、固定路線バスが成り立ちにくい。  
一方で個別タクシーではコストが高い。  
予約型乗合は中間解になる。

効果:

- 移動手段確保。
- 高齢者の外出支援。
- 自治体補助の効率化。
- 地域生活維持。

KPI:

- 予約件数。
- 乗合率。
- 1人あたり運行コスト。
- 通院・買い物利用者数。
- 利用者満足度。

注意点:

- 高齢者の予約手段。
- 既存交通との役割分担。
- 採算性。
- ドライバー確保。
- 安全管理。

GDでの使い方:

```text
地方の公共交通では、利用促進より交通空白解消が先です。定時定路線にこだわらず、予約型乗合交通や公共ライドシェアで最低限の移動手段を確保すべきです。
```

## 実例カード

### 実例1: 食品ロス量464万トン

令和5年度の日本の食品ロス量は約464万トン。事業系が約231万トン、家庭系が約233万トンと推計されている。

思考パターン:

```text
食品ロスは家庭と事業者の両方で発生
→ 事業者だけ、消費者だけでは解けない
→ 需要予測、値引き、てまえどり、家庭在庫管理を組み合わせる
```

GDでの使い方:

```text
食品ロスは事業系と家庭系がほぼ半分ずつあるため、小売・外食のDXと消費者行動変容をセットで考える必要があります。
```

### 実例2: 食品ロス削減推進法

食品ロス削減推進法は、国、地方公共団体、事業者、消費者などの責務を明らかにし、食品ロス削減を総合的に推進する法律。

思考パターン:

```text
食品ロスは社会全体で発生
→ 事業者・消費者・自治体が関わる
→ 法律で責務と基本方針を示す
```

GDでの使い方:

```text
食品ロス削減は企業努力だけでなく、自治体や消費者も含む社会全体の取組です。
```

### 実例3: 地域公共交通のリ・デザイン

国土交通省は、地域公共交通のリ・デザインや交通空白解消を進めている。優良事例では、NPOと市が連携し、住民ドライバーによる公共ライドシェアを導入した例も紹介されている。

思考パターン:

```text
地方の公共交通が縮小
→ 行政・事業者だけでは維持が難しい
→ NPOや住民も含めた地域交通へ再設計する
```

GDでの使い方:

```text
地方の交通課題では、従来のバス・タクシーだけでなく、公共ライドシェアや住民互助型の交通も選択肢になります。
```

## お題別の解き方

### お題1: フードロスを減らすには

最初の発言:

```text
食品ロスは、事業系と家庭系に分けて考えたいです。今回は短期で効果が出やすい小売・外食の事業系ロスに絞り、需要予測、値引き、寄付の3段階で考えませんか。
```

論点:

- どこでロスが発生しているか。
- 作りすぎ・仕入れすぎか、売れ残りか。
- 消費者行動をどう変えるか。
- 寄付や再流通はできるか。

施策案:

1. AI需要予測・自動発注。
2. 期限近商品のダイナミック値引き。
3. フードシェアリング。
4. てまえどりポイント。
5. フードバンク連携。

発表結論:

```text
私たちは、小売・外食向けの食品ロス削減プラットフォームを提案します。POS、天気、曜日、イベント情報を使って需要を予測し、発注量を最適化します。販売段階では、期限近商品に対して動的値引きとアプリ通知を行い、売れ残った商品はフードシェアリングやフードバンクへ流します。これにより、廃棄削減と粗利改善を両立します。
```

### お題2: ITと環境を組み合わせた施策

最初の発言:

```text
環境テーマは広いので、今回は消費者行動と企業オペレーションの両方を変えられる食品ロス削減に絞るのがよいと思います。
```

論点:

- 環境価値だけで行動が変わるか。
- 企業の利益にも効くか。
- 消費者が不便に感じないか。
- データで効果測定できるか。

施策案:

1. 需要予測。
2. 廃棄量可視化。
3. てまえどりポイント。
4. 期限近商品クーポン。
5. CO2削減量の可視化。

発表結論:

```text
ITと環境を組み合わせるなら、食品ロス削減が有効です。需要予測で作りすぎを防ぎ、期限近商品にはポイントやクーポンを付け、消費者が得をしながらロス削減に参加できる仕組みにします。環境価値だけでなく、廃棄コスト削減と粗利改善をKPIに置くことで、企業も継続しやすくなります。
```

### お題3: 公共交通機関の利用促進

最初の発言:

```text
公共交通利用促進は、都市部では自家用車からの転換、地方では交通空白の解消に分けて考えたいです。今回は、利用者の不便さを下げるMaaSと、地方向けの予約型乗合交通を組み合わせたいです。
```

論点:

- 都市部か地方か。
- 通勤・通学か観光か通院か。
- 利便性で車に勝てるか。
- 高齢者が使えるか。
- 交通事業者間で連携できるか。

施策案:

1. MaaSアプリ。
2. 観光周遊パス。
3. 混雑情報。
4. 予約型乗合交通。
5. 公共ライドシェア。

発表結論:

```text
公共交通利用促進には、都市部と地方で施策を分けるべきです。都市部では、鉄道、バス、シェアサイクルを一括検索・決済できるMaaSで、自家用車より分かりやすい移動体験を作ります。地方では、固定路線バスだけでは維持が難しいため、予約型乗合交通や公共ライドシェアを組み合わせ、通院・買い物・観光の移動を支えます。
```

## 施策評価軸

GDで施策を比較するときは、この6つを使う。

```text
効果:
廃棄量、CO2、公共交通利用、移動困難者支援にどれだけ効くか。

実現性:
既存データ、既存事業者、自治体連携で実行できるか。

経済性:
企業や交通事業者が赤字にならず続けられるか。

行動変容:
消費者・利用者が実際に行動を変えるか。

公平性:
高齢者やデジタル非利用者を排除しないか。

継続性:
一回限りのキャンペーンでなく運用として回るか。
```

発言例:

```text
施策を効果と実現性で比較すると、啓発キャンペーンよりも、需要予測と値引き最適化の方が食品ロス削減に直接効きやすいと思います。
```

```text
公共交通では、アプリだけでなく、電話予約や紙の案内も残さないと高齢者が使いにくいです。
```

## ありがちな失敗

### 失敗1: 啓発だけにする

悪い例:

```text
食品ロス削減のポスターを作ります。
```

改善:

```text
啓発だけでなく、需要予測、値引き、ポイント、寄付ルートなど、行動が変わる仕組みを作る必要があります。
```

### 失敗2: 環境価値だけで押す

悪い例:

```text
環境に良いので消費者に協力してもらいます。
```

改善:

```text
消費者にはポイントや値引き、企業には廃棄コスト削減など、経済的メリットも設計するべきです。
```

### 失敗3: 公共交通アプリだけで解決する

悪い例:

```text
公共交通アプリを作れば利用者が増えます。
```

改善:

```text
情報提供だけでなく、便数、乗継、予約、決済、ラストワンマイルまで改善しないと利用は増えません。
```

### 失敗4: 地方と都市を同じ施策にする

悪い例:

```text
全国で同じ公共交通施策を導入します。
```

改善:

```text
都市部は混雑・乗継・自家用車転換、地方は交通空白・高齢者移動・通院買い物が課題なので、施策を分けるべきです。
```

### 失敗5: 寄付すればよいで終わる

悪い例:

```text
余った食品は寄付します。
```

改善:

```text
寄付には温度管理、回収ルート、受取時間、責任分界が必要です。マッチングだけでなく物流運用まで設計する必要があります。
```


```text
公共交通は、都市部の利用促進と地方の交通空白解消で課題が違うので、分けて議論したいです。
```

```text
啓発も必要ですが、行動が変わる仕組みとして、ポイント、値引き、予約、受け取りやすさまで設計した方がよいと思います。
```

### 施策を絞る時

```text
短期で効くのは需要予測と値引き最適化、中期ではフードシェアリングや寄付ルート、長期では消費者の購買行動変容だと思います。
```

```text
社会的意義だけでなく、事業者の収益性、自治体の運用、消費者の行動変容まで含めて設計する必要があります。
```

## 最強の提案パッケージ

### 食品ロス削減プラットフォーム

対象:

- 食品スーパー。
- コンビニ。
- 外食チェーン。
- 自治体。
- フードバンク。

課題:

- 需要予測が難しい。
- 売れ残りが出る。
- 値引きが属人化。
- 寄付・再流通の仕組みが弱い。
- 消費者が期限の長い商品を選ぶ。

施策:

1. POS、天気、曜日、イベント情報で需要予測する。
2. 発注量・製造量を自動提案する。
3. 賞味期限と販売速度に応じて値引きタイミングを最適化する。
4. 期限近商品をアプリ通知し、ポイントを付ける。
5. 売れ残りをフードシェアリングやフードバンクへ流す。
6. 店舗ごとの廃棄量、廃棄コスト、CO2削減量を可視化する。

KPI:

- 食品廃棄量。
- 廃棄率。
- 粗利率。
- 期限近商品販売率。
- 寄付量。
- 廃棄コスト。
- CO2削減量。

発表例:

```text
私たちは、食品ロス削減プラットフォームを提案します。
小売・外食では、需要より多く仕入れる・作ることで食品ロスが発生します。
そこで、POS、天気、曜日、イベント情報を使って需要を予測し、発注量や製造量を最適化します。
販売段階では、期限近商品を動的に値引きし、アプリで通知します。
それでも余った食品は、フードシェアリングやフードバンクに流すことで、廃棄量と廃棄コストを下げます。
```

### 地域交通リ・デザイン

対象:

- 地方自治体。
- バス会社。
- 鉄道会社。
- 観光地。
- 高齢者。
- 観光客。

- バス路線縮小。
- 高齢者の通院・買い物移動。
- 観光地の二次交通不足。
- 自家用車依存。
- 公共交通の情報分断。

施策:

1. 鉄道、バス、タクシー、シェアサイクルを一括検索・決済できるMaaSを整備する。
2. 都市部・観光地では周遊パスと混雑情報を提供する。
3. 地方では予約型乗合交通を導入する。
4. 交通空白地域では公共ライドシェアを活用する。
5. 高齢者向けには電話予約、紙の時刻表、地域窓口を残す。

KPI:

- 公共交通利用者数。
- 予約型交通利用件数。
- 乗合率。
- 1人あたり運行コスト。
- 観光回遊数。
- 自家用車利用削減。
- 利用者満足度。

発表例:

```text
私たちは、地域交通リ・デザインを提案します。
都市部や観光地では、鉄道、バス、シェアサイクル、タクシーを一括検索・決済できるMaaSを整備し、自家用車より分かりやすい移動体験を作ります。
一方、地方では固定路線バスだけでは維持が難しいため、予約型乗合交通や公共ライドシェアを組み合わせ、通院・買い物・観光の移動を支えます。
高齢者向けには電話予約も残し、デジタルだけに依存しない設計にします。
```
