# 00_Dashboard/AGENTS.md

## 目的

このフォルダは、Obsidian Basesによる一覧確認に使う。
本文を書く場所ではなく、企業・面接対策・GD対策・選考ログ・メモ素材を横断して確認する場所である。

## 推奨Base

```text
企業一覧.base
面接対策一覧.base
GD対策一覧.base
選考ログ一覧.base
メモ素材一覧.base
```

## 方針

- ESは独立Baseにせず、`02_Companies/企業名/ES/` の企業別ビューとして扱う。
- 自己分析・業界研究・Dailyは独立Baseにしない。
- 面接で使う共通回答は `面接対策一覧.base` で見る。
- 企業固有の作戦は `企業一覧.base` で見る。
- 原典・草案・素材メモは `メモ素材一覧.base` で見る。

## 編集ルール

- Dashboard内には長文メモを置かない。
- Baseで使うProperties名は勝手に変更しない。
- 一覧で見たい情報は、本文だけでなくPropertiesにも入れる。
