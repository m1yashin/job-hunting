# 02_共通対策/面接/AGENTS.md

## 文字コード

このファイルとこのフォルダ配下のMarkdownファイルは、文字化けを防ぐためUTF-8で開く。

## 目的

このフォルダには、企業横断で使う面接用の実戦メモを置く。

面接前にすぐ見返せる少数ファイルに絞り、企業別の志望理由、想定質問、逆質問、面接ログは `01_企業別/企業名/` に置く。

## 推奨構成

```text
02_共通対策/面接/
  自己紹介.md
  大学祭_ES基準と口頭補完.md
  強み.md
  弱み.md
  研究説明.md
  キャリア軸・就活軸.md
  逆質問.md
```

## 置き場所の使い分け

- `自己紹介.md` には、30秒版・1分版・話す要素・深掘り対策を置く。
- `大学祭_ES基準と口頭補完.md` を大学祭ガクチカの正本とし、本人提示のES全文、短い回答、役割、工夫、苦労、仕事への接続、口頭補完を一元管理する。別の `ガクチカ.md` は作らない。
- `強み.md` と `弱み.md` には、人柄系質問への回答骨子と具体例、改善行動を置く。
- `研究説明.md` には、非専門家向けの研究説明、AI活用への接続、研究の深掘り対策を置く。
- `キャリア軸・就活軸.md` には、なぜIT、なぜSIer、なぜPM・上流工程、AI活用への考え方を置く。
- `逆質問.md` には、企業横断で使える逆質問の型を置く。
- 企業別の志望理由、企業別の想定質問、企業別の逆質問、直前確認は `01_企業別/企業名/` に置く。
- 実際の面接ごとの記録と復習は `01_企業別/企業名/ログ/` に置く。

## Properties

共通面接メモは以下を基本にする。

```yaml
---
type: interview_common_prep
theme:
use_for: []
source_notes: []
---
```

`status` は共通面接メモには原則として付けない。進捗管理が必要な場合だけ、企業別の面接対策やESで使う。

## 編集方針

- 丸暗記用ではなく、話す内容の骨子として作る。
- 面接前に開くファイルを増やしすぎない。
- 企業別の内容を共通メモへ混ぜない。
- 一文を長くしすぎない。
- 抽象的な強みだけで終わらせず、具体的な行動を入れる。
- 研究説明は、面接官が非専門でも理解できるようにする。
- PM・上流工程志望では、調整力だけでなく、構造化・意思決定・価値理解を示す。
- 逆質問は、仕事内容・判断基準・顧客理解・成長環境を聞く形にする。
