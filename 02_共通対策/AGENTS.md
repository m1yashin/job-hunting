# 02_共通対策/AGENTS.md

## 文字コード

このファイルとこのフォルダ配下のMarkdownファイルは、文字化けを防ぐためUTF-8で開く。

## 目的

このフォルダには、企業横断で再利用する面接・GD・ES対策と、業界研究・企業比較を置く。

特定企業のES、面接、GD、志望理由、企業研究は `01_企業別/企業名/` に置く。

## 推奨構成

```text
02_共通対策/
  面接/
    自己紹介.md
    大学祭_ES基準と口頭補完.md
    強み.md
    弱み.md
    研究説明.md
    キャリア軸・就活軸.md
    逆質問.md
  GD/
    型/
  ES/
    ES_評価.md
    志望理由作り方.md
    志望理由ES設計の教科書.md
  業界研究/
  企業比較/
```

## 置き場所のルール

- `面接/` は、自己紹介、ガクチカ、強み、弱み、研究説明、キャリア軸・就活軸、企業横断の逆質問を置く。
- `GD/` は、GDの型、発言テンプレ、評価ポイントを置く。
- `ES/` は、ES評価基準、志望理由の作り方など企業横断の作成ルールを置く。
- `業界研究/` は、業界構造、ビジネスモデル、主要企業、比較軸、市場・技術・採用トレンド、業界課題を事実と出典を中心に整理する。
- `企業比較/` は、業界内の主要企業比較を事実と出典を中心に整理する。
- 個別企業の競合比較は `01_企業別/企業名/企業研究/競合比較.md` に置く。
- 個別企業の志望理由、想定質問、逆質問、ES、ログは `01_企業別/企業名/` に置く。
- 原典資料や未整理メモは `03_メモ素材/` に置く。

## 情報の扱い

- 業界研究・企業比較は、公式情報や信頼できる出典に基づく事実を中心にする。
- 口コミ、SNS、OB訪問メモは事実の根拠にせず、使う場合は「参考情報」または「要確認」とする。
- 確認日と出典URLを残し、不明な事実を断定しない。
- 面接・GD・ES対策は、企業横断で再利用できる内容に絞る。
- 特定企業にしか使えない内容を共通対策へ混ぜない。
- `status` は進捗管理が必要なノートだけに付ける。
